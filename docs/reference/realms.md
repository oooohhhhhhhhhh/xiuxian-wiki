# 境界全表

境界数据来自 `src/main/resources/game/realm_config.json`。
共 **11 个大境界**、**29 个境界条目**（`id` + `subRealm` 唯一确定一条）。

## 境界结构

| 字段 | 含义 |
| --- | --- |
| `id` | 大境界序号（0~10） |
| `subRealm` | 小境界序号（0=初期，1=中期，2=后期） |
| `name` | 境界显示名 |
| `description` | 境界描述文案 |
| `requiredExp` | 突破到此境界**累计**所需经验 |
| `requiredSpiritStones` | 突破到此境界所需灵石 |
| `hpBonus` / `mpBonus` / `attackBonus` / `defenseBonus` / `speedBonus` / `spiritBonus` | 属性加成 |
| `unlockSkillId` | 突破到此境界解锁的技能 ID（0=无） |

::: tip 小境界只有部分大境界有
`凡人`（id 0）与 `金仙`（id 10）**只有 `subRealm=0` 一个条目**；
`炼气期`~`真仙`（id 1~9）各有初期/中期/后期三个条目。
:::

## 修炼速度倍率

`cultivationPerSecond` 段定义基础修炼速度：

```json
"cultivationPerSecond": {
  "baseValue": 1,
  "realmMultiplier": [1.0, 1.5, 2.5, 4.0, 6.0, 10.0, 18.0, 32.0, 55.0, 90.0, 150.0]
}
```

`realmMultiplier` 数组按**大境界 `id`** 索引（0~10）：

| 大境界 | id | 倍率 |
| --- | --- | --- |
| 凡人 | 0 | 1.0 |
| 炼气期 | 1 | 1.5 |
| 筑基期 | 2 | 2.5 |
| 金丹期 | 3 | 4.0 |
| 元婴期 | 4 | 6.0 |
| 化神期 | 5 | 10.0 |
| 合体期 | 6 | 18.0 |
| 大乘期 | 7 | 32.0 |
| 渡劫期 | 8 | 55.0 |
| 真仙 | 9 | 90.0 |
| 金仙 | 10 | 150.0 |

即**基础每秒修炼量 = `baseValue` × `realmMultiplier[当前大境界]`**，
之后再乘以季节、地图灵气、灵根、功法、称号、天象、阵法、Buff 等各项倍率
（完整链路见[修炼系统](/player/cultivation)）。

::: tip 这是"基础值"，不是最终值
`realmMultiplier` 只反映境界带来的差异。实际每秒灵力还要叠加上面那一长串倍率，
所以同境界的两个玩家修炼速度可能相差数倍。
:::
