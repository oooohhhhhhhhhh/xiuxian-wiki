# 境界突破与天劫

积累足够修为（经验）与灵石后，玩家执行 `/突破` 晋升境界（`RealmService.tryBreakthrough`）。**同大境界内的小境界突破直接成功**；**跨大境界突破需要渡天劫**，按成功率判定、有失败惩罚。整个判定在数据库事务 + 行锁（`SELECT FOR UPDATE`）内进行，防止并发重复结算。

## 突破条件

突破至下一境界需同时满足（`RealmService.tryBreakthrough`）：

1. 未达最高境界（金仙），且当前境界配置存在；
2. 经验 ≥ 下一境界的 `requiredExp`；
3. 灵石 ≥ 下一境界的 `requiredSpiritStones`（`requiredSpiritStones > 0` 时才校验并扣除）；
4. 不在突破冷却期内（`last_breakthrough_time` 起算）。

成功后：扣除 `requiredExp` 经验与 `requiredSpiritStones` 灵石；六维属性分别增加下一境界的 `hpBonus/mpBonus/attackBonus/defenseBonus/speedBonus/spiritBonus`；**生命与法力回满**；写入本次突破时间并进入冷却。跨大境界成功另有额外效果（见下）。

## 突破冷却

冷却时长按**突破成功后的当前大境界**（`player.realm` 索引）从 `BREAKTHROUGH_COOLDOWN_SECONDS` 取值：

| 当前境界 | 冷却 |
|----------|------|
| 凡人 | 10 分钟 |
| 炼气 | 30 分钟 |
| 筑基 | 1 小时 |
| 金丹 | 2 小时 |
| 元婴 | 4 小时 |
| 化神 | 8 小时 |
| 合体 | 12 小时 |
| 大乘 | 1 天 |
| 渡劫 | 2 天 |
| 真仙 | 3 天 |

## 七类天劫

跨大境界突破时按**当前（旧）大境界**从 `TRIBULATION_REALMS` 匹配可用天劫并随机取一种（匹配不到时全量随机），7 类天劫与对应属性加成如下：

| 天劫 | 触发场景（当前境界 → 突破至） | 简述（代码叙事） | 对应属性成功率加成 |
|------|------|------|------|
| 雷劫 | 凡人 / 炼气 / 筑基（→炼气/筑基/金丹） | 九天神雷当头劈下 | 防御 / 500 |
| 心魔劫 | 金丹（→元婴） | 执念化魔，心神剧震 | 神识 / 400 |
| 风火劫 | 元婴（→化神） | 阴风与三昧真火炼体 | 速度 / 300 |
| 水劫 | 化神（→合体） | 玄冥弱水倾泻，每滴重逾千斤 | 防御 / 350 |
| 五行劫 | 合体（→大乘） | 五行之力暴走，大道规则混乱 | (攻击+防御+神识) / 1200 |
| 阴阳劫 | 大乘（→渡劫） | 黑白雷霆织成太极图 | (神识×2+防御) / 900 |
| 轮回劫 | 渡劫 / 真仙（→真仙/金仙） | 六道轮回之门显现 | 神识 / 300 |

> 七种天劫的阶段分配以代码 `RealmService` 的 `TRIBULATION_REALMS` 数组为准（注意：心魔劫只对应金丹、风火劫只对应元婴、水劫只对应化神、五行劫只对应合体、阴阳劫只对应大乘，旧版文档按「跨越多境界」描述的阶段映射已过时）。

## 成功率公式

大境界突破（渡劫）的成功率逐项累加（`executeTribulation` / `executeTribulationWithConn`）：

```
基础成功率   = BASE_SUCCESS_RATES[当前大境界]
             = 凡人80% / 炼气80% / 筑基70% / 金丹60% / 元婴50%
               / 化神40% / 合体30% / 大乘20% / 渡劫15% / 真仙10%

灵力加成     = min(15, 神识/50)           %   （每 50 点神识 +1%，上限 +15%）
灵根加成     = 按品级（下表），混沌灵根觉醒规则见后
天劫属性加成 = min(10, 对应表达式 × 100)  %   （表达式见上表，整体上限 +10%）
渡劫丹加成   = +10%（背包存在「渡劫丹」时自动消耗 1 颗）

最终成功率   = min(95, 基础 + 灵力 + 灵根 + 天劫属性 + 渡劫丹)
判定         = random(0..9999) < 最终成功率×100 → 成功
```

### 灵根品级对成功率的修正（`RealmService.getSpiritualRootBonus`）

| 品级 | 加成 |
|------|:---:|
| 鸿蒙灵根 | +35% |
| 正·五行灵根 | +25% |
| 天灵根 | +15% |
| 异灵根 | +10% |
| 双灵根 | +5% |
| 三灵根 | 0 |
| 四象灵根 | **-5%** |
| 混沌灵根（杂灵根） | **元婴期前 -10%**；达到元婴期及以后（`realm >= 4`）**+15%** |

> 混沌灵根的「大器晚成」按代码以突破发起时的当前境界判定：凡人→元婴（realm 0~3）阶段均为 -10%，从元婴期起（realm ≥ 4，即元婴→化神及以后各次大境界突破）变为 +15%。

## 渡劫丹

| 项目 | 数值（代码） |
|------|------|
| 物品 | `渡劫丹`（`mtxgdn:tribulation_pill`，稀有度 史诗 EPIC，消耗品） |
| 生效方式 | 渡劫开始前检查背包：存在则**自动扣除 1 颗**并在成功率中加 **+10%**（`RealmService`） |
| 手动服用 | 仅提示「下次突破大境界时自动生效 +10%」（`TribulationPillEffect`，实际加成仍在突破流程结算） |
| 获取途径 | 灵石商店（售价 500 灵石，`EconomyService` 商店行注明「突破时 +10% 成功率」）；炼丹配方可炼制；游历奇遇/秘境掉落（如 `StrangeTowerEvent` 宝藏、秘境战利品池） |

## 渡劫失败惩罚

- **经验损失**：扣除 **下一境界 `requiredExp` 的 1/3**（向下取整，不低于 0）；
- **身受重伤**：HP 强制降为 **1**；
- **混沌灵根淬炼**：若为混沌灵根（`LATE_BLOOMER`），失败反而淬炼肉身，攻击/防御/速度获得少量成长——代码为 `max(1, (int)(3 × 0.05))` = **+1**（乘 `1 + 灵根本身加成`，混沌无加成故 +1）各 1 点；
- 不进入突破冷却（失败不写 `last_breakthrough_time`）。

## 跨大境界成功额外效果

- 晋升境界并照常加成、回满生命法力（见 [境界一览](./realm-list)）；
- 混沌灵根额外成长攻击/防御/速度：`max(1, (int)(5 × 0.05))` = **+1** 各 1 点；
- 授予称号「破天者」（`sky_breaker`），并触发境界/战力类称号集中检查。
