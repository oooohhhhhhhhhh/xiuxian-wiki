# 境界突破与天劫

玩家积累足够经验与灵石后，可通过突破晋升境界。**小境界**（同一大境界内）100% 成功；**大境界**突破会触发**天劫**，存在失败风险。

## 突破条件

突破到下一境界需要同时满足：

1. 经验 ≥ 下一境界的 `requiredExp`
2. 灵石 ≥ 下一境界的 `requiredSpiritStones`
3. 不在突破冷却期内

突破成功后扣除对应经验与灵石，并立即获得该境界的属性加成（HP / MP / 攻击 / 防御 / 速度 / 灵力，HP 与 MP 补满）。

## 突破冷却

每次成功突破后进入冷却，冷却时长由**当前大境界**决定：

| 当前境界 | 冷却 |
|----------|------|
| 凡人 | 10 分钟 |
| 炼气 | 30 分钟 |
| 筑基 | 1 小时 |
| 金丹 | 2 小时 |
| 元婴 | 4 小时 |
| 化神 | 8 小时 |
| 合体 | 12 小时 |
| 大乘 | 1 天 |
| 渡劫 | 2 天 |
| 真仙 | 3 天 |

## 大境界突破成功率

大境界突破的基础成功率随境界递减（`BASE_SUCCESS_RATES`，按当前大境界索引）：

| 突破 | 基础成功率 |
|------|:---:|
| 凡人 → 炼气 | 80% |
| 炼气 → 筑基 | 80% |
| 筑基 → 金丹 | 70% |
| 金丹 → 元婴 | 60% |
| 元婴 → 化神 | 50% |
| 化神 → 合体 | 40% |
| 合体 → 大乘 | 30% |
| 大乘 → 渡劫 | 20% |
| 渡劫 → 真仙 | 15% |
| 真仙 → 金仙 | 10% |

| 修正项 | 数值 |
|--------|------|
| 灵力加成 | 每 50 点灵力 +1%，上限 **+15%** |
| 鸿蒙灵根 | +35% |
| 正·五行灵根 | +25% |
| 天灵根 | +15% |
| 异灵根 | +10% |
| 双灵根 | +5% |
| 三灵根 | 0 |
| 四象灵根 | **-5%** |
| 混沌灵根 | 大乘期前 **-10%**；大乘期及以后（觉醒）**+15%** |
| 渡劫丹 | **+10%**（突破时自动消耗 1 颗） |
| 天劫对应属性 | 按天劫类型不同（见下表） |

### 天劫对应属性加成

| 天劫 | 对应属性加成（百分点） |
|------|------|
| 雷劫 | 防御 / 500 |
| 心魔劫 | 灵力 / 400 |
| 风火劫 | 速度 / 300 |
| 水劫 | 防御 / 350 |
| 五行劫 | (攻击 + 防御 + 灵力) / 1200 |
| 阴阳劫 | (灵力 × 2 + 防御) / 900 |
| 轮回劫 | 灵力 / 300 |

## 天劫类型

大境界突破时，根据**当前境界**从可匹配的天劫中随机选择一种（7 种）：

| 天劫 | 对应境界（当前境界） | 描述 |
|------|------|------|
| 雷劫 | 凡人 / 炼气 / 筑基 | 九天神雷当头劈下 |
| 心魔劫 | 金丹 / 元婴 | 执念化魔，心神剧震 |
| 风火劫 | 筑基 / 金丹 / 元婴 | 阴风与三昧真火炼体 |
| 水劫 | 金丹 / 元婴 / 化神 | 玄冥弱水倾泻 |
| 五行劫 | 元婴 / 化神 | 五行之力暴走 |
| 阴阳劫 | 合体 | 黑白雷霆织成太极图 |
| 轮回劫 | 合体 | 六道轮回之门显现 |

## 渡劫失败惩罚

- 扣除**下一境界需求经验的 1/3**
- **HP 降为 1**（身受重伤）
- 混沌灵根（大器晚成）：失败反而淬炼肉身，攻击 / 防御 / 速度小幅成长
