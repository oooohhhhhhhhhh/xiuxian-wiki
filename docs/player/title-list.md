# 称号列表

内置 **19 个称号**、**5 档稀有度**，全部数据取自 `TitleRegistry`（`com.mtxgdn.game.title`）静态注册。数值字段在 `Title` 实体上的映射顺序为 `title(key, name, desc, rarity, requiredRealm, atk, hp, mp, def, spd, spi, cult, exp, drop)` → 攻击 / 生命 / 法力 / 防御 / 速度 / 灵力。

**境界要求**使用大境界序号：0 凡人 → 1 炼气 → 2 筑基 → 3 金丹 → 4 元婴 → 5 化神 → 6 合体 → 7 大乘 → 8 渡劫 → 9 真仙 → 10 金仙。百分比列为修炼速度 / 经验 / 掉落率加成。

各称号的授予路径说明见 [称号系统](./titles)。
