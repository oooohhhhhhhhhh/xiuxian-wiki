# 答题系统（默认隐藏 / 关闭）

> ⚠️ **当前默认状态：隐藏关闭**。`application.yml` 中 `quiz.enabled: false` 时，答题系统的**全部功能均不可用**：
> - `/题库` `/quiz` 管理指令**不注册**（/help 不显示，调用无响应）
> - 题库**自动收集**（从聊天中识别出题 + 答案并入库）**停止**
> - **命中即答**（发送含题干的消息自动回答案）**停止**
> - `QuizAutoResponder` 自动答题器不可用
>
> 如需恢复，将 `quiz.enabled` 改为 `true` 并重启服务即可（三种消息管线：OneBot 服务端 / OneBot 客户端 / QQ 官方均受此开关控制）。

## 机制说明（启用后）

QQ 机器人内置**题库自动收集 + 命中即答**机制：机器人会从群聊 / 私聊消息中自动识别「出题 + 答案」格式并收入题库，此后任何人发送包含该题干的消息，机器人自动回复答案。

| 项目 | 说明 |
|------|------|
| 题库文件 | `data/quiz/questions.json`（缺失时读内置资源，再无则用内置默认题） |
| 题目结构 | `{id, question, answer(1~4)}` |
| 自动收集 | 识别前缀行（`第N题 / 题目开始 / 请听题 ...`）与选项行（`1、...`），从「正确答案是：N」提取答案并自动入库 |
| 自动应答 | 消息归一化（去空白 / 标点 / 小写）后包含匹配，命中即回复「题干 + 修仙答 + 答案」 |
| 优先级 | 答题命中**优先于指令执行**（命中即拦截） |
| 奖励 / 次数 | **无**（纯文本自动回复，无奖励、无每日次数限制） |

## 题库管理指令（仅 quiz.enabled=true 时存在）

| 指令 | 说明 |
|------|------|
| `/题库` `/quiz` | 显示题库统计与用法 |
| `/题库 list` | 列出所有题目 |
| `/题库 show <id>` | 查看指定题目 |
| `/题库 add <1~4> <题干>` | 添加题目 |
| `/题库 delete <id>` | 删除题目 |

> 题库管理指令无权限限制（任何 QQ 用户均可操作）。

## 批量导入

- `BatchQuizImporter`：命令行批量导入 CSV（格式：`答案(1-4),题目`），追加到题库并续号
- `QuizDataCleaner`：把含选项的题目 JSON 转换为纯 `{id, question, answer}` 数组
