# 阵法系统

阵法（`/阵法`）为洞府提供灵气汇聚、修炼加成、防御与心魔抵抗等增益，布置需要**灵石**，激活后有时限。

## 阵法一览（5 种）

| 阵法 | 基础时长 | 花费基准（灵石/级） | 灵气汇聚 | 修炼加成 | 防御加成 | 心魔抵抗 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 聚灵阵 | 60 分钟 | 100 | +5%/级 | +3%/级 | - | +1/级 |
| 护山大阵 | 120 分钟 | 300 | - | - | +10/级 | - |
| 迷踪阵 | 30 分钟 | 50 | - | - | +5/级 | - |
| 净化阵 | 90 分钟 | 200 | - | +2%/级 | - | +2/级 |
| 时间加速阵 | 15 分钟 | 500 | +3%/级 | +5%/级 | - | - |

- 等级上限：**5 级**；布置花费 = `基准 × 等级`
- 每个玩家同时只能激活 **1 个**阵法

## 使用规则

| 操作 | 说明 |
|------|------|
| 布置 | 需拥有**洞府**；消耗灵石，激活后持续基础时长（可升级延长） |
| 升级 | 按新等级重算花费与数值（消耗灵石） |
| 拆除 | 手动停用 |
| 过期 | 服务端每 60 秒扫描过期阵法自动停用 |

## 效果生效点

| 效果 | 生效位置 |
|------|------|
| 灵气汇聚 | 洞府收集灵石时加成：`灵气 × (100 + 加成) / 100` |
| 修炼加成 | 洞府冥想经验：`100 + (洞府加成 + 阵法加成) × 10` |
| 心魔抵抗 | 洞府冥想心魔判定：`洞府等级 + 阵法心魔抵抗/2` |
| 防御加成 | 当前仅展示（未接入战斗） |

> 说明（源码现状）：阵法道具（聚灵阵 / 护山大阵 / 净化阵 道具物品）目前为占位物品，**不能用于布置阵法**；布置只能通过命令花灵石。
