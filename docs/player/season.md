# 季节系统

季节不再是种田的附属设定，而是**全服共享的「天道时序」**——影响闭关修炼、晨修经验、灵石获取、物品掉落与作物生长。可通过 `GET /api/game/season`、WebSocket `season_info`、QQ `/种田` 查看当前季节与更替倒计时。

## 更替模式

由 `application.yml` 配置（`season.mode`）：

| 模式 | 说明 |
|------|------|
| `calendar`（默认） | 按真实月份划分四季：3-5 月春、6-8 月夏、9-11 月秋、12-2 月冬 |
| `cycle` | 按固定小时循环更替（`season.cycle_hours`，默认 **6 小时**一季），更替时 WebSocket 全服广播 |

服务端每 10 秒检查一次季节状态；`cycle` 模式下季节更替会向全服广播 `season_change` 消息。

## 四季全局倍率

| 玩法 | 春 | 夏 | 秋 | 冬 |
|------|:---:|:---:|:---:|:---:|
| 修炼倍率 | ×1.10 | ×1.05 | **×1.15** | ×0.95 |
| 晨修 / 机缘经验倍率 | = 修炼倍率 | = 修炼倍率 | = 修炼倍率 | = 修炼倍率 |
| 游历收益倍率 | ×1.10 | ×1.00 | ×1.05 | ×0.90 |
| 灵石获取倍率 | ×1.00 | ×0.95 | **×1.20** | ×0.90 |
| 物品掉落倍率 | ×1.05 | ×1.00 | **×1.15** | ×0.90 |

## 作物生长加成

不同元素属性的作物在不同季节获得生长速度修正（`Season.getGrowthModifier`）：

| 季节 | 加速 | 减速 |
|------|------|------|
| 春 | 木 / 灵 ×1.25 | 火 ×0.75 |
| 夏 | 火 ×1.30 | 水 / 冰 ×0.80 |
| 秋 | 金 / 土 ×1.20 | 木 ×0.90 |
| 冬 | 水 / 冰 ×1.30 | 火 ×0.70 |
