# 灵根系统

灵根是角色**创建时随机抽取、终生可变**的核心天赋：决定角色的六维基础属性（生命 / 法力 / 攻击 / 防御 / 速度 / 神识）与各种战斗、修炼、经济特效。玩家创建角色即获得 1 种灵根；达到**金丹期**后可通过 **灵根重铸** 消耗「乾坤造化丹 + 灵石」重新随机抽取。

全部灵根由枚举 `com.mtxgdn.game.entity.SpiritualRoot` 定义（17 个常量、8 个品级），属性为**百分比加成**，作用在角色基础值/当前属性上；特效由 `SpecialEffect` 枚举承载并嵌入战斗、修炼、游历、坊市、农场、突破、技能熟练度等各系统。

## 抽取规则

### 创建角色

`PlayerService.createPlayer` 调用 `SpiritualRoot.drawRandom`：按枚举顺序的固定权重表（`WEIGHTS = {1, 1, 3,3,3,3,3, 5,5,5, 10,10,10, 10,10, 14, 6}`）抽取，**跳过 `initializable = false` 的正·五行灵根**。初始池总权重 = 101：

| 结果 | 权重 | 概率 |
|------|:---:|:---:|
| 鸿蒙灵根 | 1 | ≈0.99% |
| 天灵根（5 种） | 各 3 | 每种 ≈2.97%（合计 ≈14.85%） |
| 异灵根（3 种） | 各 5 | 每种 ≈4.95%（合计 ≈14.85%） |
| 双灵根（3 种） | 各 10 | 每种 ≈9.90%（合计 ≈29.70%） |
| 三灵根（2 种） | 各 10 | 每种 ≈9.90%（合计 ≈19.80%） |
| 四象灵根 | 14 | ≈13.86% |
| 混沌灵根 | 6 | ≈5.94% |

新角色基础属性按固定值套用灵根百分比加成（`createPlayer`）：生命 **100**、法力 **50**、攻击 **10**、防御 **5**、速度 **5**、神识 **5**（加成公式：`基础值 + (int)(基础值 × 加成比例)`，向下取整）。

### 灵根重铸（金丹期解锁）

`SpiritualRootCommand.doRecast` + `PlayerService.updateSpiritualRoot`：

- **条件**：当前境界 ≥ **金丹期**（`realm >= 3`）
- **消耗**：`乾坤造化丹`（`mtxgdn:qiankun_zaohua_dan`）× **1** + **500,000** 灵石（等值下品灵石；事务内先扣道具与灵石，任一步失败回滚）
- **抽取**：`SpiritualRoot.drawRandomForRecast` 允许正·五行灵根入池（权重 1），重铸池总权重 = **102**（正·五行 ≈0.98%，其余概率按池大小相应缩小）
- **生效**：立即按新灵根重置六维基础属性为「基础值 × 新灵根加成」（基础值同上：100/50/10/5/5/5），当前 HP 不超过新上限；**不可撤销**
- 指令：`/灵根 重铸`（别名 `/灵根 recast`），操作计入玩家行为日志

## 特效作用点（按代码）

`SpecialEffect` 在各系统内的实际接入位置与数值：

| 特效 | 灵根 | 作用系统 | 代码行为（已核验） |
|------|------|----------|------|
| `CULTIVATION_EFFICIENCY` +15% | 木水 | 修炼 / 离线 / 晨修 | 修炼总倍率 ×(1+0.15)（`PlayerService.cultivationMultiplier`）；离线结算再乘一次（`OfflineRewardService`）；晨修经验 ×(1+0.15)（`DailyService`） |
| `SPIRIT_STONE_DROP` +20% | 火土木 | 晨修灵石 / 战斗掉落 / 秘境奖励 | 晨修灵石 ×(1+0.20)（`DailyService`）；PVE 战胜灵石掉落 ×(1+0.20)（`CombatService`）；秘境灵石奖励同规则（`SecretRealmService`） |
| `MONSTER_EXP` +25% | 金火 | PVE 经验 | 击败妖兽经验 ×(1+0.25)（`CombatService`） |
| `CRIT_CHANCE` +5% | 太乙金 | 战斗（PVE/PVP/宗门战） | 按效果值加入暴击率 |
| `CRIT_DAMAGE` +30% | 惊雷 | 战斗 | 暴击伤害按效果值放大 |
| `DAMAGE_BOOST` +10% | 离火 | 战斗 | 造成伤害 ×(1+0.10) |
| `DAMAGE_REDUCTION` +15% | 厚土 | 战斗 | 受到的伤害按效果值减免 |
| `SKILL_DAMAGE` +15% | 玄冰 | 战斗 | 技能伤害 ×(1+0.15) |
| `MP_COST_REDUCTION` -20% | 玄冥水 | 战斗 | 技能法力消耗按效果值降低 |
| `REGENERATION` 3% | 青帝木 | 战斗 | 战斗中每回合按效果值回复生命 |
| `EXPLORATION_CD` -30% | 巽风 | 游历 | 游历冷却 = 基础冷却 ×(1-0.30)（`ExplorationService` / `ExploreCommand`） |
| `TRADE_FEE_HALF` | 土金 | 坊市 | 卖方手续费减半（5% → 2.5%，`TradeService`）；**拍卖行 7% 手续费不受影响** |
| `PROFICIENCY_BOOST` +30% | 金水木 | 技能熟练度 | 熟练度获取 ×(1+0.30)（`SkillService.addProficiency`） |
| `LATE_BLOOMER` | 混沌 | 突破 / 心魔 / 农场 | 见下方说明 |
| `FIVE_ELEMENTS_AFFINITY` ×1.0 | 正·五行 | 农场 | 任意作物五行加成 +20%（`FarmService`） |
| `ALL_EFFECTS_ENHANCE` ×0.5 | 鸿蒙 | 农场 | 农场五行加成 ×(1+0.5)（`FarmService`，鸿蒙固定 0.50 → 0.75） |
| `NONE` | 四象 | — | 无特效 |

> **说明（源码现状）**：
> 1. 「所有灵根效果增强 50%」（鸿蒙）的增强语义已统一为 `SpiritualRoot.effectEnhancementMultiplier()`（鸿蒙 =1.5，其余 =1.0）与 `getEnhancedEffectValue(e)` 入口，供所有消费灵根数值特效的位置复用；单灵根设定下当前实际被放大的路径仍只有**农场契合加成**（`FarmService` 鸿蒙 0.50 → 0.75），战斗/修炼/坊市等其他系统数值不受鸿蒙影响（无平衡变化）。
> 2. 「五行 100% 亲和」的 `FIVE_ELEMENTS_AFFINITY` 在代码中没有独立的通用结算点，农场中体现为任意作物 +20% 加成。
> 3. 混沌灵根的「大器晚成」实际表现：突破成功时额外成长攻击/防御/速度（基数为 `5 × 0.05` 取整、至少 +1）；**渡劫失败时反而淬炼肉身**获得小幅成长（基数为 `3 × 0.05` 取整、至少 +1）；心魔抗性额外 +2（抵消杂灵根品级 -2% 的不利）；渡劫成功率见 [境界突破与天劫](./realm-breakthrough)。

### 农场五行加成（灵根 ↔ 作物）

`FarmService.getSpiritualRootBonus` 按灵根与作物元素（金/木/水/火/土/冰/光等）匹配返回加成系数（0~0.75），叠加后作为作物产量/生长加成之一：

| 灵根 | 契合元素加成 | 不契合元素加成 |
|------|:---:|:---:|
| 太乙金 / 青帝木 / 玄冥水 / 离火 / 厚土 | 对应单元素 +30% | +10% |
| 玄冰（冰）/ 巽风（光）/ 惊雷（火） | 对应元素 +25% / +20% / +20% | +5% / +5% / +5% |
| 金火（金火）、木水（木水）、土金（土金） | 两种元素 +15% | +5% |
| 火土木（火土木）、金水木（金木水） | 三种元素 +10% | +3% |
| 正·五行灵根 | 任意元素 +20% | 任意元素 +20% |
| 鸿蒙灵根 | 任意元素 +50%（再 ×1.5 → **+75%**） | 同左 |
| 其余（四象 / 混沌） | 0 | 0 |

## 灵根共鸣

连续活跃（晨修计入 `total_active_days`）达到里程碑时，灵根与天地灵气产生共鸣，**永久提升属性**（`DailyService.awardResonance`，每个里程碑仅发放一次，代码按「活跃总天数」判定、非连续天数）：

| 里程碑 | 发放（套用灵根本身百分比后计入属性） |
|:---:|------|
| 7 天 | 生命 +50、法力 +25、攻击 +5、防御 +3、速度 +3、神识 +5（均先乘本灵根对应加成） |
| 30 天 | 生命 +100、法力 +50、攻击 +10、防御 +5、速度 +5、神识 +10（同上） |

> 加成先经 `root.applyXBonus(base)` 处理，即高加成灵根（鸿蒙 30%、太乙金 15% 等）实际到账略高于表内基准值。

## 境界与灵根

灵根品级同时影响**突破/渡劫成功率**（`RealmService.getSpiritualRootBonus`）：鸿蒙 +35%、正·五行 +25%、天灵根 +15%、异灵根 +10%、双灵根 +5%、三灵根 0、四象 **-5%**、混沌灵根在**元婴期前 -10%**、达到**元婴期及以后**（品级判定 `realm >= 4`）觉醒为 **+15%**。详见 [境界突破与天劫](./realm-breakthrough)。
