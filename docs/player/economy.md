# 经济与货币

经济系统包含**金币**与**四级灵石**两套货币，以及每日签到、物品回收、灵石商店、灵石提纯、拆零、灵庄存款、灵石加速修炼、兑换码等玩法。坊市挂单与竞拍行的手续费规则见 [坊市交易](./market)。

## 货币体系

| 货币 | 存放位置 | 说明 |
|------|----------|------|
| 金币 | 角色属性（`players.gold`） | 独立于背包，不可提现 |
| 下品灵石 | 背包物品 `mtxgdn:spirit_stone_low` | 基础货币，等值 1 |
| 中品灵石 | 背包物品 `mtxgdn:spirit_stone_mid` | = **1000** 下品 |
| 上品灵石 | 背包物品 `mtxgdn:spirit_stone_high` | = **10⁶**（100 万）下品 |
| 极品灵石 | 背包物品 `mtxgdn:spirit_stone_supreme` | = **10⁹**（10 亿）下品 |

- 相邻等级 **1:1000**（`CurrencyEffect.EXCHANGE_RATES = {1, 1000, 10⁶, 10⁹}`），各等级灵石的物品价格即其下品等值，可直接转化为[能量](./energy)
- 高等级灵石有持有上限：中品 **999,999**、上品 **9,999**、极品 **99**（下品无上限）；发放灵石时按面额从大到小自动分配，超限部分保留在下品
- 支付时自动跨等级扣除并按下品灵石找零（`ItemService.removeSpiritStones`）
- 物品道具类货币：`gold_bag`（金袋，使用获得 100 金币）、`spirit_stone_pouch`（灵石袋，使用获得 5 下品灵石），均不可交易

## 金币 ↔ 灵石

服务层（`EconomyService.exchangeGoldToStones` / `exchangeStonesToGold`）提供双向兑换，**汇率不对称**，形成损耗：

```
10 金币 → 1 下品灵石      （兑换后向下取整）
1 下品灵石 → 5 金币
```

入口已打通（此前两个服务方法无任何界面入口）：

- QQ：`/货币兑换 金币 <数量>` 或 `/货币兑换 灵石 <数量>`（别名 `/币兑`、`/currency_exchange`，权限码 `game.player.info`，模块 `economy`）
- REST：`POST /api/game/economy/currency-exchange`，body `{"type": "goldToStones" | "stonesToGold", "amount": <数量>}`（权限码 `game.player.info`）
- 均调服务层 `EconomyService.exchangeGoldToStones / exchangeStonesToGold`（事务内扣加；余额不足 / 参数非法返回业务信息，不扣任何资源）

## 每日签到

7 天一轮的固定奖励循环（连续第 8 天回到第 1 天；断签从第 1 天重新开始），数据存 `player_economy`：

| 天数 | 奖励 |
|:---:|------|
| 1 | 下品灵石 ×50 |
| 2 | 下品灵石 ×80 + 灵草 ×2 |
| 3 | 下品灵石 ×120 + 铁矿石 ×3 |
| 4 | 下品灵石 ×160 + 回血丹 ×2 |
| 5 | 下品灵石 ×200 + 强化石 ×1 |
| 6 | 下品灵石 ×260 + 回蓝丹 ×2 |
| 7 | 下品灵石 ×350 + 修炼丹 ×1 |

- QQ：`/签到`（别名 `/signin`）；REST：`POST /api/game/economy/signin`
- 每日限一次（事务内行锁防并发双签）；奖励按背包 upsert 自动叠加

## 物品回收

```
回收灵石 = 物品价格(price) × 数量 × 30%（向下取整，最低 1）
```

- 灵石类物品不可回收（本身就是货币）；`tradeable=false` 的不可交易物品不可回收
- QQ：`/回收 <物品名> [数量]`（别名 `/recycle`）；REST：`POST /api/game/economy/recycle`（body：`itemKey`、`quantity`）

## 灵石提纯

消耗**大量同阶灵石 + 洞府灵气**把低阶灵石升为高阶，有概率失败（失败消耗不返还），并受境界限制：

| 提纯 | 境界要求（realm 编号） | 消耗 | 基础成功率 |
|------|:---:|------|:---:|
| 下品 → 中品 | 筑基（2） | 1000 下品 + 100 灵气 | 90% |
| 中品 → 上品 | 元婴（4） | 1000 中品 + 1000 灵气 | 60% |
| 上品 → 极品 | 大乘（7） | 1000 上品 + 10000 灵气 | 30% |

- 成功率修正：`min(98%, 基础率 + min(15%, 灵力(spirit) / 2000))`
- 灵气来自[洞府系统](./cave)，未开辟洞府或灵气不足无法提纯
- QQ：`/提纯 <下品|中品|上品>`（别名 `/purify`、`/灵石提纯`，权限码 `game.stone.purify`）
- REST：`POST /api/game/economy/purify`（body：`grade` 0|1|2）

## 灵石拆零

高等级 → 低等级无损兑换（按 1:1000 汇率），**只能高换低**，反向请用提纯：

- QQ：`/灵石兑换 [数量] <从> <到>`（别名 `/石兑`，权限码 `game.player.info`），如 `/灵石兑换 1 极品 下品`
- 未注册 REST 路由

## 灵石加速修炼

燃烧下品灵石换取额外修炼经验，需先处于修炼状态（`/修炼`）：

```
每 100 下品灵石 = 1 小时加速（×1.5，即 50% 额外经验）
额外经验 = 境界每秒修炼经验 × 加速小时 × 3600 × 50%
```

- 数量向下取整为 100 的倍数，不足 100 会拒绝
- QQ：`/修炼加速 <灵石数量>`（别名 `/boost`）；REST：`POST /api/game/economy/cultivate-boost`（body：`stones`）

## 灵庄（灵石存款）

灵石存入灵庄生息，记录于 `player_bank` 表：

| 类型 | 期限 | 利率 | 备注 |
|------|:---:|:---:|------|
| 活期 | 随时可取 | 日利 **0.2%**（按天复利） | 30 天复利约 6.2% |
| 七日期 | 7 天 | 到期 **+4%** | 提前取出无利息 |
| 月满期 | 30 天 | 到期 **+15%** | 提前取出无利息 |
| 季定期 | 90 天 | 到期 **+40%** | 提前取出无利息 |

- 起存 **100** 下品灵石；利息与本金均以下品灵石计（活期利息按实际存入天数复利，`principal × (1 + 日利率)^天数 − 本金`）
- 存取走跨等级灵石支付/找零；条件更新防并发双取
- QQ：`/灵庄`（查看）、`/灵庄 存入 <活期|7天|30天|90天> <数量>`、`/灵庄 取出 <编号>`、`/灵庄 利率`（别名 `/bank`）
- REST：`GET /api/game/economy/bank/info`、`POST /api/game/economy/bank/deposit`（body：`type`=current/fixed_7/fixed_30/fixed_90、`amount`）、`POST /api/game/economy/bank/withdraw`（body：`depositId`）

> `/灵庄 利率` 命令帮助文案与结算利率一致（活期 0.2% / 7 天 4% / 30 天 15% / 90 天 40%），实际收益以代码结算为准。

## 兑换码

管理员创建奖励码，玩家输入兑换（`redeem_codes` + `redeemed_codes` 表，每玩家每码限一次）：

- 奖励类型：金币 / 下品灵石 / 经验（界面显示为「灵力」）/ 物品（按 key 与数量）
- 有总使用次数（`max_uses`）、有效期（`expires_at`）与状态控制；码不区分大小写
- 玩家：`/兑换 <兑换码>`（别名 `/redeem`，权限码 `game.redeem.code`）；REST：`POST /api/game/redeem`（body：`code`）
- 管理员：管理后台「兑换码」模块或 `POST /api/admin/redeem-codes` 系列接口（权限码 `admin.redeem.code.manage`）
