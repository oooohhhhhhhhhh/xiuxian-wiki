# 经济与货币

经济系统包含**金币**与**四级灵石**两套货币，以及签到、回收、灵石提纯、灵庄、拍卖、修炼加速、兑换码等玩法。

## 货币体系

| 货币 | 说明 |
|------|------|
| 金币 | 玩家属性（`players.gold`），独立于背包 |
| 下品灵石 | 基础货币，等值 1 |
| 中品灵石 | = **1000** 下品 |
| 上品灵石 | = **100 万** 下品 |
| 极品灵石 | = **10 亿** 下品 |

灵石为背包物品（`mtxgdn:spirit_stone_low/mid/high/supreme`），相邻等级 **1:1000**。支付时自动跨等级扣除并找零；高等级灵石有持有上限（中品 999,999 / 上品 9,999 / 极品 99）。

**金币 ↔ 灵石**（汇率不对称，形成损耗）：10 金币 → 1 下品灵石；1 下品灵石 → 5 金币。

## 每日签到

7 天一轮的固定奖励循环（第 8 天回到第 1 天）：

| 天数 | 奖励 |
|:---:|------|
| 1 | 下品灵石 ×50 |
| 2 | 下品灵石 ×80 + 灵草 ×2 |
| 3 | 下品灵石 ×120 + 铁矿石 ×3 |
| 4 | 下品灵石 ×160 + 回血丹 ×2 |
| 5 | 下品灵石 ×200 + 强化石 ×1 |
| 6 | 下品灵石 ×260 + 回蓝丹 ×2 |
| 7 | 下品灵石 ×350 + 修炼丹 ×1 |

指令：`/签到` `/signin`；REST：`POST /api/game/economy/signin`。

## 物品回收

```
回收灵石 = 物品价格 × 数量 × 30%（向下取整，最低 1）
```

- 灵石类物品不可回收；不可交易物品不可回收

## 灵石提纯

低阶灵石升为高阶（需要**洞府灵气**，失败消耗不返还）：

| 提纯 | 境界要求 | 消耗 | 基础成功率 |
|------|:---:|------|:---:|
| 下品 → 中品 | 筑基 | 1000 下品 + 100 灵气 | 90% |
| 中品 → 上品 | 元婴 | 1000 中品 + 1000 灵气 | 60% |
| 上品 → 极品 | 大乘 | 1000 上品 + 10000 灵气 | 30% |

成功率修正：`min(98%, 基础率 + min(15%, 灵力/2000))`。

指令：`/提纯 <下品|中品|上品>`；REST：`POST /api/game/economy/purify`。

## 灵石兑换（拆零）

高等级 → 低等级无损兑换（1:1000 汇率）：`/灵石兑换 [数量] <从> <到>`（`/石兑`）。与提纯相反，本操作无成本。

## 灵庄（灵石存储）

| 类型 | 期限 | 利率 |
|------|:---:|:---:|
| 活期 | 随时可取 | 日利 0.5%（按天复利） |
| 七日期 | 7 天 | 到期 +3% |
| 月满期 | 30 天 | 到期 +10% |
| 季定期 | 90 天 | 到期 +25% |

- 起存 **100** 下品灵石；定期**提前取出损失全部利息**
- 指令：`/灵庄`、`/灵庄 存入 <活期|7天|30天|90天> <数量>`、`/灵庄 取出 <编号>`、`/灵庄 利率`
- REST：`GET /api/game/economy/bank/info`、`POST .../deposit`、`POST .../withdraw`

## 拍卖行

- 发布：`/拍卖 出售 <物品> <数量> <起价> [小时]`（时长 1~72 小时，默认 24）
- 出价：`/拍卖 出价 <编号> <价格>`（出价即冻结灵石，被超时原额退还）
- 成交：卖家得 `成交价 - 7% 手续费`（手续费入系统账户）；**流拍物品退回卖家**
- 指令：`/拍卖`、`/拍卖 我的`；REST：`GET /api/game/economy/auction/items|my`、`POST .../create|bid`

## 修炼加速

```
每 100 下品灵石 = 1 小时加速（×1.5 效率）
加速经验 = 每秒经验(仅境界倍率) × 小时数 × 3600 × 50%
```

需**正在修炼**。指令：`/修炼加速 <灵石>` `/boost`；REST：`POST /api/game/economy/cultivate-boost`。

## 兑换码

管理员创建的奖励码（金币 / 灵石 / 经验 / 物品），每玩家每码限兑一次，有使用次数与有效期限制。

- 玩家：`/兑换 <兑换码>`、`POST /api/game/redeem`
- 管理员：`/api/admin/redeem-codes`（管理后台「兑换码」模块）
