# PVE 战斗与 Boss

PVE 战斗出现在**游历遭遇妖兽**与**秘境探索**（普通妖兽 + 守护者 Boss + 团队副本 Boss）中，采用自动回合制。

## 战斗流程

- **先手**：玩家速度 ≥ 怪物速度则玩家先手
- **回合上限**：30 回合（普通 PVE）；50 回合（团队 Boss）
- 每回合开始先结算玩家灵根**再生**（青帝木灵根每回合回复 3% 最大生命）
- 玩家自动施放第一个满足蓝耗的攻击技能；无可用技能则普攻
- 治疗 / 辅助技能在自动战斗中不施放

## 伤害公式

### 玩家 → 怪物

```
技能伤害 = 基础伤害 × (1 + 15%×(等级-1))          # 每级 +15%
         × (1 + 玄冰灵根技能伤害加成)              # 玄冰 +15%
普攻伤害 = 最终攻击 + 最终灵力                      # PVE 普攻含灵力！
总伤害   = (技能/普攻) × (1 + 离火增伤) × 暴击倍率
         + 随机(-5 ~ +5) - 怪物防御/3
暴击率   = 最终速度/200 + 太乙金灵根加成(+5%)
暴击倍率 = 1.5 + 惊雷灵根加成(+0.3)
```

### 怪物 → 玩家

```
伤害 = 怪物攻击 + 随机(-4 ~ +4) - 玩家最终防御/3
     × (1 - 厚土灵根减伤 15%)
```

## 妖兽属性

普通妖兽随玩家境界缩放（`Monster.random`）：

```
攻击 = 5 + 境界×12；防御 = 2 + 境界×4；速度 = 3 + 境界×2；HP = 30 + 境界×35
经验 = 境界×80 + 随机；金币/灵石 = 随机（随境界缩放）
掉落率 = 30%~45%
```

## 胜利奖励

| 奖励 | 公式 / 规则 |
|------|------|
| 经验 | 怪物经验奖励；**金火灵根** +25% |
| 金币 | 直接获得 |
| 灵石 | **火土木灵根** +20% |
| 物品 | 概率掉落（掉落表按怪物类型） |

## 守护者 Boss（单人秘境）

秘境 10% 概率遭遇守护者 Boss：

```
HP = 80 + 境界×120；攻击 = 15 + 境界×30；防御 = 8 + 境界×12；速度 = 5 + 境界×5
掉落率 = 60%~85%，掉落表更丰富（修炼丹/灵石袋/灵剑/护身玉/护符/残卷等）
```

Boss 名称按境界档位（见 [秘境探索](./secret-realm)）。失败则扣除实际受到的伤害。

## 团队副本 Boss（Raid）

多人组队挑战**三形态 Boss**：

| 形态 | 属性倍率（HP/攻/防/速） | 玩家削弱 | 触发 |
|:---:|:---:|:---:|------|
| 形态 1 | 1.0 / 1.0 / 1.0 / 1.0 | 5% | 初始 |
| 形态 2 | 1.4 / 1.3 / 1.2 / 1.1 | 10% | 剩余 HP < 66% |
| 形态 3 | 2.0 / 1.6 / 1.4 / 1.2 | 15% | 剩余 HP < 33% |

- 每回合全体存活玩家依次攻击，Boss 随机攻击一名玩家
- 通关奖励按队伍人数加成后平分；尾刀玩家获得「副本征服者」称号
- 详见 [秘境探索·团队副本](./secret-realm)

## 已知现状（源码事实）

- 当前实现中，PVE 战斗的 MP 消耗与怪物血量累计存在缺陷（每回合蓝量按初始值计算、怪物血量不跨回合累计），实际表现为「单回合伤害 ≥ 怪物初始 HP 即获胜」
- 普通怪与 Boss 的物品掉落表使用裸 key，实际**不掉落物品**（仅经验 / 金币 / 灵石）
