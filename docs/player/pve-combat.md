# PVE 战斗与 Boss

PVE 战斗出现在**游历遭遇妖兽**、**秘境探索**（普通妖兽 / 秘境守护者 / 团队副本）以及**快捷战斗入口**（`/战斗`、`/讨伐`、`/boss`）中，全部为**自动回合制**：进入战斗后玩家与怪物按回合自动行动，全程无需手动操作，战报逐回合生成。

## 回合制战斗结算（核心机制）

战斗统一由 `CombatService` 执行，单人 PVE（普通妖兽、秘境守护者、快捷战斗）与团队 Boss 共用同一套结算规则：

- **参战前提**：玩家生命值必须大于 0（`HP ≤ 0` 视为重伤，无法进入战斗）。
- **先手判定**：玩家最终速度 ≥ 怪物速度时玩家先手，否则怪物先手。
- **回合上限**：单人 PVE 为 **30 回合**；团队 Boss 战为 **50 回合**。回合耗尽时按血量判定（PVE 中 30 回合未击杀怪物视为战斗结束并结算失败）。
- **每回合流程**：
  1. 先结算玩家灵根**再生**特效（青帝木灵根等每回合恢复 `最大生命 × 3%`）；
  2. 轮到玩家行动：若当前生命 ≤ 最大生命的一半且法力足够，则优先自动施放**治疗技能**；否则自动施放第一个「法力足够且不在冷却中」的**攻击技能**；无可用技能则**普攻**；
  3. 玩家行动后若怪物存活，怪物反击玩家；
  4. 任一方的生命降至 0 立即结束战斗（玩家生命为 0 即战败）。

### 战斗内自动决策规则

| 规则 | 说明（源码事实） |
|------|------------------|
| 技能冷却 | 同一技能两次使用至少间隔 1 回合（`当前回合 - 上次使用 ≥ 2`），冷却中的技能不会被选中 |
| 蓝耗成长 | 技能蓝耗随等级提升：`基础蓝耗 × (1 + (等级-1) × 15%)`；玄冥水灵根（法力消耗降低特效，-20%）可再减免 |
| 伤害成长 | 技能伤害随等级提升：`基础伤害 × (1 + (等级-1) × 15%)` |
| 防御技能 | 开局自动运转「防御型技能」（技能类型 2，如金刚护体）：减伤 = `min(30, 蓝耗 × 50 / 100)`%，即**本场战斗最高减伤 30%**，整场持续生效 |
| 治疗时机 | 仅当生命 ≤ 50% 且法力足够、治疗技能不在冷却时施放（回春术 / 甘霖普降等） |
| Buff 生效 | 反弹类 Buff（如反弹丹）会把受到的怪物伤害按百分比**反弹给怪物**，反弹可反杀怪物 |

### 玩家 → 怪物伤害

```
技能伤害 = 基础伤害 × (1 + (等级-1)×15%)
         × (1 + 玄冰灵根技能伤害加成 15%)          # SKILL_DAMAGE 特效
普攻伤害 = 最终攻击 + 最终灵力                       # PVE 普攻包含灵力
再乘    = × (1 + 离火灵根增伤 10%)                   # DAMAGE_BOOST 特效
暴击    = × (1.5 + 惊雷灵根暴击伤害加成 0.3)          # 命中暴击时
最终    = 上述结果 + 随机(-5 ~ +5) - 怪物防御/3
保底    = 最终伤害至少为 1
暴击率  = min(60%, 最终速度/400) + 太乙金灵根暴击率加成 5%
```

> 暴击率中「速度折算部分」随速度收益递减且**上限 60%**（`速度/400`，不再无上限）；灵根暴击率加成（太乙金 +5%）在该封顶值之上再叠加。暴击倍数基础 1.5，惊雷灵根 +0.3。

### 怪物 → 玩家伤害

```
伤害 = 怪物攻击 + 随机(-4 ~ +4) - 玩家最终防御/3
     × (1 - 厚土灵根减伤 15%)                        # DAMAGE_REDUCTION 特效
     （团队 Boss 战中再按形态削弱玩家防御，见下文）
保底 = 最终伤害至少为 1
```

### 战后状态

- 战斗结束（无论胜负）都会**持久化玩家真实剩余 HP/MP**，战斗损耗不会自动恢复——受伤后需疗伤、服药或依靠自动疗伤恢复。
- 战斗中使用的每个技能结算 **+15 熟练度**。
- 战报在多人场景（PVP、团队）中会分段发送，每段至多约 5 行，回合间自动换段。

### 随机妖兽（游历 / 秘境小怪）

随机妖兽名字由 14 个前缀 × 12 个名字随机组合（如「烈焰妖狼」「霜月魅狐」），属性按境界线性缩放并带有随机浮动：

```
基础生命 = 30 + 境界×35    生命 += 随机(境界×20 + 10)
基础攻击 = 5  + 境界×12    攻击 += 随机(境界×8 + 5)
基础防御 = 2  + 境界×4     防御 += 随机(境界×3 + 2)
基础速度 = 3  + 境界×2     速度 += 随机(境界×3 + 1)
经验     = 境界×80 + 随机(境界×40 + 10)
金币     = 随机(境界×20 + 10)
灵石     = 随机(境界×10 + 5)
掉落率   = 30% ~ 45%
```

- 游历遭遇按**玩家境界**缩放；秘境小怪按**秘境需求境界**缩放（高境界玩家在低阶秘境不会遇到过强的怪）。
- 掉落表共 6 组普通掉落，每组 1 件：灵草 / 铁矿 / 疗伤丹 / 回气丹 / 聚气丹 / 妖兽内丹，命中后随机取一组发放 1 件。

### 固定妖兽（`/战斗` 快捷入口）

`/战斗` 从以下 4 只**固定数值**妖兽中均等随机一只（数值不随玩家境界变化）：

| 妖兽 | 生命 | 攻击 | 防御 | 速度 | 掉落率 | 经验 / 金币 / 灵石 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 野猪精 | 80 | 20 | 50 | 3 | 30% | 100 / 20 / 5 |
| 青狼 | 100 | 30 | 70 | 4 | 40% | 150 / 30 / 8 |
| 黑熊妖 | 150 | 60 | 100 | 5 | 35% | 200 / 40 / 10 |
| 白骨精 | 180 | 40 | 150 | 6 | 30% | 250 / 50 / 15 |

## Boss 机制

### 单人秘境守护者 Boss

进入秘境后有概率遭遇「秘境守护者」Boss（普通秘境约 **10%**；需求境界 ≥ 6 的高阶秘境——合体期及以上——遭遇概率提高，约为 **20%**）。守护者按秘境境界从 **11 档命名表**取名称与描述（以「境界档位 − 1」索引，下限 1 档）：

| 档位示例 | Boss 名称 |
|----------|-----------|
| 草原 | 草原霸主·奔雷兽（→ 各境界递进：暗影领主·噬魂蛛皇、兽王·金翼裂天雕、遗迹守卫·青铜巨像 …） |
| 高层 | 真仙·紫霄道祖、金仙·鸿蒙道尊 |

守护者属性按境界线性缩放并带随机浮动：

```
生命 = 80 + 境界×120 + 随机(境界×60 + 30)
攻击 = 15 + 境界×30  + 随机(境界×15 + 10)
防御 = 8  + 境界×12  + 随机(境界×6 + 5)
速度 = 5  + 境界×5   + 随机(境界×4 + 3)
经验 = 境界×250 + 随机(境界×120 + 50)
掉落率 = 60% ~ 85%
```

- 守护者掉落表更丰富：3 组掉落轮流抽组，含修炼丹、灵石袋、灵剑、护身玉、护符、残卷、低级剑谱、增益丹药、速行符、灵泉水、天玉等。
- **高阶秘境**（需求境界 ≥ 6）击败守护者后，额外**必定掉落 1 件传说材料**：五色神石 / 龙心 / 麒麟血 / 凤凰胆 / 万年灵芝 / 天元丹 / 乾坤造化丹。
- 单人守护者战仍受 30 回合上限约束，失败扣除实际损失的生命。

> 说明：Boss 为**形态变身制**，没有怒气 / 狂暴条机制——普通 Boss 直接按境界生成，团队 Boss 靠血量阈值切换形态提升战力（见下）。

### 团队副本 Boss（多形态）

组队进入团队副本秘境后，清完小怪出现**三形态最终 Boss**（`BossForm.createFormsForRealm`，按秘境境界取对应名字与描述，如 11 档 × 三形态命名）：

| 形态 | 属性倍率（生命/攻击/防御/速度） | 玩家削弱 | 出现条件 |
|:---:|:---:|:---:|------|
| 第一形态 | 1.0 / 1.0 / 1.0 / 1.0 | 5% | 战斗开始 |
| 第二形态 | 1.4 / 1.3 / 1.2 / 1.1 | 10% | Boss 生命低于 66% |
| 第三形态 | 2.0 / 1.6 / 1.4 / 1.2 | 15% | Boss 生命低于 33% |

- **变身**：Boss 生命跨过 66% / 33% 阈值时切换形态，更新名称、描述、攻击与防御（生命总量跨形态累计）；切换后战报提示新形态。
- **玩家削弱**：玩家对 Boss 的输出按形态削弱百分比扣减（输出 × (1 − 削弱)）；Boss 反击玩家时同样按削弱比例降低玩家防御效果。
- **回合节奏**：每回合全体存活玩家按序各攻击一次，随后 Boss 随机攻击一名存活玩家；被击倒的玩家退出本场战斗。
- **结束条件**：Boss 生命归零且至少一名玩家存活 = 胜利（记录尾刀玩家）；50 回合内未击杀、或全队阵亡 = 失败。

## 组队 PVE（团队副本）

组队系统用于团队副本（详见下方流程）：

- 队伍 **2 ~ 5 人**，纯内存存储（无数据库表）；队长创建并邀请，被邀请者 `/组队 接受` 入队；**队长退出即解散全队**，人数不足 2 人自动解散。
- 组队本身**无属性加成**，仅作为团队副本的成员集合。

### 副本流程（队长发起）

1. 队长创建队伍并邀请队友：`/组队 创建`、`/组队 邀请 <玩家名>`；成员用 `/组队 接受` / `/组队 拒绝` 回应。
2. 队长输入 `/组队 副本 <秘境名>` 发起（仅队长可发起，目标秘境需支持团队副本模式）。
3. 校验：全体成员境界 ≥ 秘境需求境界、生命 > 0、且各自处于秘境冷却之外（任一不满足则整体失败）；通过后**全体成员进入秘境冷却**。
4. **小怪关卡**：共 `max(2, 秘境境界)` 波，每波 1 ~ 2 只随机妖兽；每只妖兽由存活成员依次单独交手（逐场 PVE 结算），任一成员战败即离场；全员阵亡则挑战中止。
5. 清完小怪进入**最终 Boss 战**（上文三形态规则）。

### 通关奖励（源码事实）

- 基础奖励按秘境境界：`基准经验 = (境界+1) × 500`、`基准金币 = (境界+1) × 300`、`基准灵石 = (境界+1) × 100`。
- **人数加成**：总奖励 × `(1 + 0.2 × (人数 − 1))`，再**均分**给每个**存活**成员。
- **物品掉落**：通关后每个存活成员按奖励表**独立判定**（命中率 50%，奖励表按秘境境界 6 档：灵草 / 修炼丹 / 精钢剑 / 火龙诀 / 五色神石 / 龙心等）。
- **尾刀荣誉**：完成最后一击的玩家获得**「副本征服者」称号**（`raid_conqueror`）。
- 团队副本失败或全灭则无通关奖励。

## 胜利奖励结算

| 奖励 | 规则（源码事实） |
|------|------------------|
| 经验 | 直接发放怪物经验；**金火灵根**（妖兽经验特效）再 ×1.25 |
| 金币 | 直接发放怪物金币奖励 |
| 灵石 | 发放怪物灵石奖励；**火土木灵根**（灵石掉落特效）再 ×1.20 |
| 物品 | 判定概率 = 怪物掉落率 × **季节掉落倍率**；命中后从掉落表随机取 1 件，经物品注册表校验存在才发放（key 均带 `mtxgdn:` 前缀，自动兼容补全） |
| 熟练度 | 本场战斗中使用的每个技能 +15 |

> 季节与每日天象可能通过倍率影响掉落与产出（PVE 掉落判定已乘入季节掉落倍率），详见 [季节系统](../player/season)。

## 已知现状（源码事实）

- 普通妖兽与秘境守护者现使用**带命名空间前缀的合法掉落 key**，并经物品注册表校验后才发放——普通怪与 Boss **均可真实掉落物品**（旧版文档所述「掉落失效」问题已修复）。
- 技能冷却为「间隔至少 1 回合」，治疗技能仅在生命 ≤ 50% 时自动施放，攻击技能在 PVE 中按玩家技能列表顺序取第一个可用者（**不区分战斗策略**，战斗策略只影响 PVP）。
- 战前、战后 HP/MP 均按真实数值持久化；生命不足时无法再次进入战斗。
- 战斗中**不存在五行相克 / 五行属性伤害**机制；伤害侧的元素类加成仅来自灵根特效（技能伤害 / 总伤害 / 暴击）。
- 团队副本 Boss 按剩余血量推进形态（血量 <66% 进入第二形态、<33% 进入第三形态，`checkBossFormChange` 同步回写形态序号），通关结算按**最终形态**对应的奖励表与掉落概率（第二形态 0.65 / 第三形态 0.8）抽奖；若最后一击使 Boss 从高于阈值的血量被直接斩杀，则结算维持该形态之前的奖励表（原固定取第一形态 + 50% 概率的缺陷已修复）。
