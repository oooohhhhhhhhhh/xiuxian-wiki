# 制造系统

制造（炼丹 / 炼器 / 制符 / 培育种子）通过配方消耗材料 + 金币 / 灵石产出物品。共 **31 种配方**（`CraftingService.insertDefaultRecipes` 初始化），分 4 类：丹药 PILL（15）/ 装备 EQUIPMENT（7）/ 消耗品 CONSUMABLE（5）/ 种子 SEED（4）。

## 制造流程

1. 校验配方存在、境界达标（`配方需求境界`）
2. 检查材料（最多 3 种）与金币 / 灵石
3. 事务内扣除材料与费用
4. 按成功率判定：

```
成功：产出数量 × 品质倍率（普通×1 / 上品×2 / 极品×3）
      获得经验 = [minExp, maxExp] 随机 × (1 + 品质加成率×(倍率-1))
失败：材料费用照扣，获得安慰经验 = minExp / 3
```

**品质判定**：`roll < 极品率` → 极品；`< 极品率 + 上品率` → 上品；否则普通。
