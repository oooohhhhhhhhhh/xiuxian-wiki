# 制造系统

制造（`/合成`，代码归属 `CraftingService` + `CraftCommand`）让玩家消耗**材料 + 金币/灵石**，按配方产出丹药、装备、消耗品与种子。启动时 `CraftingService.insertDefaultRecipes()` 向 `recipes` 表写入 **33 种默认配方**（按名称幂等，旧库增量补齐），分为 4 类：

| 分类 | 枚举 | 配方数 |
|------|------|:---:|
| 丹药 | PILL | 17 |
| 装备 | EQUIPMENT | 7 |
| 消耗品 | CONSUMABLE | 5 |
| 种子 | SEED | 4 |

> 境界门槛使用**大境界序号**（与 `realm_config.json` 的 `id` 一致）：0 凡人 → 1 炼气 → 2 筑基 → 3 金丹 → 4 元婴 → 5 化神 → 6 合体 → 7 大乘 → 8 渡劫 → 9 真仙 → 10 金仙。

## 制造流程与判定

`craft(playerId, recipeId)` 的顺序（全部在一个数据库事务内）：

1. 校验配方存在、角色境界 ≥ 配方 `required_realm`；
2. 校验最多 3 种材料数量、金币与灵石足够；
3. 事务内扣除材料 + 金币 + 灵石；
4. 按成功率随机判定：

```
成功：先按配方品质率判定品质，产出数量 = 基础产出 × 品质倍率
      普通 NORMAL ×1 / 上品 HIGH ×2（效果翻倍）/ 极品 MAX ×3（效果三倍）
      获得经验 = [minExp, maxExp] 随机 × (1 + qualityBonusRate × (倍率 − 1))
失败：材料与费用照扣，仅获得安慰经验 = minExp / 3
```

品质判定（`determinePillQuality`）：`roll < 极品率 → 极品`；否则 `roll < 极品率 + 上品率 → 上品`；否则普通。品质判定对所有分类统一生效（当前实现未区分丹药/非丹药）。制造成功后炼丹计数 +1，并触发称号检查（炼丹学徒 / 丹道尊者，见 [称号系统](./titles)）。

**合成熟练度**（`/合成 熟练度`）：由累计制造**成功**次数派生（`players.craft_count`，每次成功 +1）——每 20 次升 1 级，上限 Lv.10；每级提供 +0.5% 制造成功率（Lv.10 共 +4.5%），单次综合成功率封顶 95%。本次成功在结算后才 +1，因此加成作用于**下一次**制造判定。

## 指令与接口

| 指令 | 说明 |
|------|------|
| `/合成` `/炼制` `/craft` | 查看制造系统概况 |
| `/合成 列表` | 列出全部配方（含成功率、材料、费用、品质率） |
| `/合成 配方 <分类>` | 按分类查看（PILL / EQUIPMENT / CONSUMABLE / SEED） |
| `/合成 制造 <配方ID>` | 制造（配方 ID 用 `/合成 列表` 查看） |
| `/合成 熟练度` | 查看合成熟练度（等级 Lv.1~10、累计成功次数、距下一级进度与当前成功率加成，见上文「合成熟练度」） |

REST 端点：`GET /game/crafting/recipes`（可选 `category` 参数）、`POST /game/crafting/craft`（body 传 `recipeId`），由 `CraftCommand` 注册。
