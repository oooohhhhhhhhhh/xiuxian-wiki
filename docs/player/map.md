# 世界地图

修仙世界由 **15 个地点**组成，玩家拥有当前位置，只能沿**相邻路线**逐点移动；不同地点提供不同的**修炼灵气加成**，部分地点有**境界门槛**或属于**安全区**。地图数据定义在 `game/service/MapService.java`（默认地点与连接常量），落库于 `map_locations` / `map_connections` 两张表（全新安装自动写入默认数据，老库启动时自动补齐缺失地点与单向连接的反向边）。

## 指令

| 指令（中文 / 英文别名） | 参数 | 说明 |
|------|------|------|
| `/地图` `/map` | 无 | 查看当前位置、区域、灵气加成与可前往的相邻地点（含路程耗时、境界不足/安全区标记） |
| `/地图 前往 <地名>` `/地图 go <地名>` | 地点名称 | 沿路线前往**相邻**地点（境界足够且冷却结束则立即到达） |
| `/地图 列表 [区域]` `/地图 list` | 可选区域名 | 浏览全地图（按区域分组）或指定区域，附简单世界脉络示意 |

- **权限码**：`game.player.info`；**分类**：探索。
- **模块门控**：挂载于内置模块 `map`。
- 位置信息同样通过 REST / WebSocket 玩家状态接口返回（当前位置、`safeZone`、灵气加成、相邻地点）。

## 世界脉络（默认连接）

地点间连边**双向**（`DEFAULT_CONNECTIONS`，共 17 条边，落库时自动补反向），相邻关系如下：

- **主线**：青云村(1) — 青云山(2) — 苍月镇(3) — 太虚城(4) — 落霞山(5) — 昆仑墟(7) — 天元古城(9) — 问道峰(10)；
- 太虚城(4) 另连 天机阁(14)、碧水潭(6)、灵药谷(13)；落霞山(5) 另连 万妖谷(12)；
- 碧水潭(6) 连 九幽渊(8) 与 东海龙宫(11)；九幽渊(8) 连 东海龙宫(11)；昆仑墟(7) 另连 白骨岭(15)；
- 苍月镇(3) 另连 灵药谷(13)；灵药谷(13) 另连 碧水潭(6)。

## 移动规则

- 只能移动到**相邻地点**（`map_connections` 中的双向连边），非相邻地点会提示可从当前位置前往的名单；
- 目标地点有境界门槛：`当前境界 ≥ 目标最低境界`，否则提示所需境界；
- 每段路程默认 **5 秒**（`travel_time_seconds`，逐边入库、最小 1 秒）；移动冷却 = `max(5, 路程耗时)` 秒，冷却期间无法再次移动；
- 冷却结束即**立即到达**（同时更新 `current_location_id` 与 `last_travel_time`）；
- 新角色默认出生在**青云村（ID 1）**（`current_location_id` 为空时回退 1）。

## 传送符

- **传送符**（`mtxgdn:teleport_talisman`，制造配方「炼制传送符」产出，材料 灵草×3 + 星沙×1）使用后**无视路线与移动冷却**直接传送至**太虚城**（主城、安全区，ID 4）；境界校验仍然保留——未达筑基的玩家无法借此进入太虚城。

## 源码事实与细节

- `/地图 列表` 的 ASCII「世界脉络」示意只画了 1~10 号主干路线，**不含** 11~15 号地点及其连边（完整数据以上表与 `map_connections` 为准）；
- 移动为「计时冷却 + 瞬移到达」而非持续行走：冷却未满时提示「正在赶路途中（还需要 X 秒到达）」；
- 地图数据是**进程内缓存**（启动后首次访问从数据库加载），由 `ensureInitialized()` 保证单次初始化。
