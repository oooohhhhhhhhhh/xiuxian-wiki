# 农场系统

农场（`/种田`）是玩家获取**灵植材料**的核心途径：种植种子、浇水施肥、防治病虫害、按品质收获。核心实现：`FarmService`（每秒后台推进全服地块状态）+ `FarmCommand`（指令层）+ `CropConfig`（16 种作物静态配置）+ `Season` / 灵根（`SpiritualRoot`）加成。

## 农田基础规则

| 参数 | 值 |
|------|------|
| 初始地块数 | 4 块 |
| 最大地块数 | 12 块 |
| 水分上限 | 100%（种下时为 100，之后**每秒 -0.1%**，约 17 分钟降至 0） |
| 肥力上限 | 100%（种下时为 0，施肥提升） |
| 枯萎 | 水分降至 0 进入枯萎；枯萎 **6 小时**内浇水可复活（水分置 50），超过则无法恢复、只能清理重种 |
| 扩建费用 | `100 × 2^(当前地块数 − 4)` 金币（第 5 块 100 → 第 12 块 12800，全扩满合计 25,500 金币） |
| 病虫害 | 种植满 5 分钟后每秒按概率发病；轻度/病害持续 30 分钟未治升级为严重 |

地块状态机：`空地 EMPTY → 已种植 PLANTED → 生长中 GROWING（每秒推进阶段）→ 可收获 READY / 枯萎 WILTED`。`FarmService` 每秒对所有生长中地块统一推进（农场模块停用时暂停结算）。

## 种植与生长

- `/种田 种植 <地块> <种子>`：消耗该种子 ×1（需背包持有、地块为空）；
- 种下时水分 = 100、肥力 = 0，并按当季与灵根计算**预计收获时间与基准产量**：

```
生长倍率 = (1 + 灵根加成) × 季节加成
生长时间 = 基础生长秒数 ÷ 生长倍率
基准产量 = 基础产量 × (1 + 灵根加成)   （存入地块，收获时参与产量计算）
```

### 灵根加成（`getSpiritualRootBonus`，按作物五行）

| 灵根 | 加成 |
|------|------|
| 鸿蒙灵根 | 全元素 +50% |
| 正·五行灵根 | 全元素 +20% |
| 五行单灵根（太乙金/青帝木/玄冥水/离火/厚土） | 对应元素 +30%，其余 +10% |
| 玄冰灵根 | 冰 +25%，其余 +5% |
| 巽风灵根 | 光 +20%，其余 +5% |
| 惊雷灵根 | 火 +20%，其余 +5% |
| 双灵根（金火/木水/土金） | 命中任一 +15%，其余 +5% |
| 三灵根（火土木/金水木） | 命中任一 +10%，其余 +3% |
| 混沌灵根 | 全元素加成后再放大 |

### 季节加成（`Season.getGrowthModifier`）

| 季节 | 加速 | 减速 |
|------|------|------|
| 春 | 木、灵 ×1.25 | 火 ×0.75 |
| 夏 | 火 ×1.30 | 水、冰 ×0.80 |
| 秋 | 金、土 ×1.20 | 木 ×0.90 |
| 冬 | 水、冰 ×1.30 | 火 ×0.70 |

季节由全服「天道时序」推进（`SeasonService`），`/种田` 总览会显示当前季节、效果与更替倒计时。

## 浇水 / 施肥 / 杀虫

| 操作 | 效果 | 说明 |
|------|------|------|
| 浇水 | 水分 +30（上限 100） | 枯萎 6 小时内地块可复活，水分置 50 |
| 施肥 | 低阶肥料 +25 / 中阶 +40 / 高阶 +60 肥力 | 每地块每次消耗 1 个肥料物品 |
| 杀虫 | 清除病虫害 | 消耗杀虫剂 ×1，仅对带虫害地块生效 |

施肥默认使用低阶肥料，可用参数指定 `low / mid / high`（或 中级/高级）。

## 收获与产量

作物成熟（READY）后可收获（支持一键收获）。产量公式（`calculateYield`）：

```
产量 = 基准产量(已含灵根加成)
     + 基准产量 × 水分/100 × 0.5          （水分加成）
     + 基准产量 × 肥力/100 × 肥力加成%     （肥力加成，系数见作物表）
     + 随机 0~2
     − 病虫害减产（轻度 20% / 病害 30% / 严重 40%，按基准产量计）
最终 = 品质倍率 × 上述合计，并夹取到 [1, 作物最大产量 × 2]
```

**品质**在成熟时按「水分、肥力、病虫害、灵根、季节」评分随机判定：

| 品质 | 产量倍率 | 判定要点 |
|------|:---:|------|
| 极品 EXCELLENT | ×2.0 | 评分高时概率命中（随机值 ≤ 评分×0.3） |
| 上品 GOOD | ×1.5 | 随机值 ≤ 评分×0.7 |
| 普通 COMMON | ×1.0 | 其余 |

评分：水分 ≥80 得 15 分（≥50 得 5）、肥力 ≥80 得 20 分（≥50 得 10）、无病虫害 +25（轻度 +5）、灵根加成 ≥20% +10、季节加成 >1.1 +10。
