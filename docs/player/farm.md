# 农场系统

农场（`/种田`）提供 4~12 块农田，种植 16 种作物，通过浇水、施肥提升产量；支持病虫害防治、一键操作、灵根与季节加成。

## 农田规则

| 参数 | 值 |
|------|------|
| 初始地块数 | 4 块 |
| 最大地块数 | 12 块 |
| 水分上限 | 100%（每秒 -1） |
| 肥力上限 | 100%（消耗肥料提升） |
| 枯萎复活窗口 | 枯萎 ≤ 1 小时可浇水复活（水分置 50） |
| 扩建费用 | `100 × 2^(当前地块数 - 4)` 金币（第 5 块 100 → 第 12 块 12800，全扩满共 25,500 金币） |
| 病虫害 | 种植 5 分钟后可能发病（每小时 2%），30 分钟未治升级为严重 |

地块状态机：`空 → 种植 → 生长（每秒推进）→ 成熟 / 枯萎`。

## 种植

- 消耗种子 ×1；种下时水分=100、肥力=0
- **灵根加成**：与作物元素匹配的灵根缩短生长时间并提高基础产量（如青帝木 +30%，鸿蒙 +75%）
- **季节加成**：春木/灵、夏火、秋金/土、冬水/冰 加速（×1.2~1.3），逆季节减速（见 [季节系统](./season)）
- 生长时间 = `基础生长秒数 / ((1 + 灵根加成) × 季节加成)`

## 浇水与施肥

- 浇水：每次 +30 水分（上限 100）；枯萎地块浇水可复活
- 施肥：消耗**肥料物品**（低阶 +25 / 中阶 +40 / 高阶 +60 肥力），每次 1 个

## 收获与产量

```
产量 = 基础产量
     + 基础产量 × 水分/100 × 0.5
     + 基础产量 × 肥力/100 × 肥力加成率
     + 随机 0~2
     - 病虫害减产（20% / 30% / 40%）
最终 = clamp(产量, 1, 最大产量 × 2)
```

**品质判定**（成熟时）：根据水分、肥力、病虫害、灵根、季节评分随机出品质：

| 品质 | 产量倍率 |
|------|:---:|
| 极品 EXCELLENT | ×2.0 |
| 上品 GOOD | ×1.5 |
| 普通 COMMON | ×1.0 |

## 病虫害

| 状态 | 减产 |
|------|:---:|
| 轻度虫害 MILD | 20% |
| 病害 DISEASE | 30% |
| 严重虫害 SEVERE | 40% |

使用**杀虫剂**（`mtxgdn:pesticide`）可清除病虫害。
