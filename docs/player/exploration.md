# 游历探索

游历（`/游历`）是玩家外出随机遭遇的核心玩法：每次游历从 **13 种随机事件**中按权重抽取一种并即时结算，可能获得经验、金币、灵石、物品，也可能遭遇战斗或陷阱损失。抽奖与结算由 `game/service/ExplorationService.java` 驱动，事件定义位于 `data/mtxgdn/explorationevent` 包（启动时经 `ExplorationEventScanner` 扫描注册），全部事件一览见 [游历事件一览](../player/exploration-events)。

## 指令

| 指令（中文 / 英文别名） | 参数 | 说明 |
|------|------|------|
| `/游历` `/explore` | 无 | 立即执行一次游历探索，返回本次遭遇的过程与收益 |
| `/游历 状态` `/游历 status` | 无 | 查看游历冷却倒计时 |

- **权限码**：`game.explore`；**分类**：探索。
- **模块门控**：指令挂载于内置玩法模块 `exploration`（`built_in_plugins` 中的「探索」），模块被停用时指令与整条游历入口一并失效。
- 游历属于**每日联动**玩法：每次成功游历都会推进「今日机缘·游历」计数，累计 3 次后领取一次经验奖励（详见 [季节系统](../player/season) 中的天象与机缘说明）；
- 游历事件只经 QQ/OneBot 子命令触发，不注册 REST 路由。

## 触发规则

| 项目 | 值 | 说明 |
|------|:---:|------|
| 基础冷却 | **300 秒（5 分钟）** | `ExplorationService.BASE_COOLDOWN_MS = 300_000`（源码注释：原 60 秒导致每日可刷上千次、灵石/物品产出失控而调高） |
| 巽风灵根（`EXPLORATION_CD`） | 冷却 **-30% → 210 秒** | 计算公式见下，效果值 0.30 |
| 重伤限制 | HP ≤ 0 无法游历 | 返回「你已重伤，无法游历，请先恢复生命值」 |
| 每日联动 | 每次游历计入「今日机缘·游历 3 次」进度 | `DailyService.onExplore()` |
| 新手引导 | 成功游历推进新手引导 `explore` 步骤 | `NewbieGuideService` |

冷却公式：

```
有效冷却 = 300_000 ms × (1 - 灵根效果值)
```

仅带 `EXPLORATION_CD` 特效的灵根生效（当前为巽风灵根，`SpecialEffect.EXPLORATION_CD, 0.30`）。冷却判定与时间戳写入在同一数据库事务内完成（行锁 + `FOR UPDATE`），从根上避免并发重复触发刷取。

> `/游历 状态` 子命令与真实判定同口径：`ExploreCommand` 直接引用 `ExplorationService.BASE_COOLDOWN_MS`（300 秒）并按同一灵根公式计算，显示的冷却/剩余时间即为真实等待时间。

## 事件抽取

13 种事件按权重抽奖，**总权重 152**（`ExplorationEventRegistry.randomByWeight`：先累加总权重，再掷 `[0, totalWeight)` 骰子按序命中）：

| 事件（key） | 权重 | 概率 | 一句话结果 |
|------|:---:|:---:|------|
| 遭遇妖兽（`monster`） | 25 | ≈16.4% | 完整回合制 PVE 战斗（上限 30 回合），胜得经验/金币/灵石与掉落 |
| 发现宝藏（`treasure`） | 25 | ≈16.4% | 金币 + 灵石（随境界缩放） |
| 采集灵草（`herb`） | 15 | ≈9.9% | 灵草 / 回血丹 / 回蓝丹 / 灵泉水 1~2 个 |
| 遇到散修（`cultivator`） | 13 | ≈8.6% | 经验 / 灵石 / 赠物三分支 |
| 发现种子（`seed`） | 12 | ≈7.9% | 种子 1~2 颗（普通 / 稀有 / 传说分层） |
| 采集材料（`material`） | 10 | ≈6.6% | 材料 1~3 个（按代码分桶抽普通/稀有/史诗） |
| 偶遇游商（`merchant`） | 10 | ≈6.6% | 强化石 / 物品 / 金币 / 灵石四分支 |
| 发现遗迹（`ruins`） | 10 | ≈6.6% | 封印宝物（40%）/ 大量灵石（35%）/ 功法残篇经验（25%） |
| 神秘奇遇（`mystery`） | 8 | ≈5.3% | 传说材料 / 钱袋 / 秘籍 / 种子 / 灵石 / 误入秘境六分支 |
| 灵泉沐浴（`spirit_spring`） | 8 | ≈5.3% | 回复 25%~50% 最大生命/法力 + 经验 + 灵泉水 |
| 遭遇陷阱（`trap`） | 7 | ≈4.6% | 损失约 10%~22.5% 最大生命（HP 最低为 1） |
| 一无所获（`nothing`） | 5 | ≈3.3% | 保底经验 `(境界+1)×10` |
| 奇遇古塔（`strange_tower`） | 4 | ≈2.6% | 至宝 / 符文经验 / 强化石 / 前人财宝四分支 |

> 各事件的概率、分支数值与奖励明细见 [游历事件一览](../player/exploration-events)。

## 结算与加成

游历成功后按以下顺序结算：

1. **事件本身**：发放经验 / 金币 / 灵石 / 物品，或扣除生命（陷阱）；
2. **季节游历加成**：全局季节对游历收益有倍率（春 ×1.10、夏 ×1.00、秋 ×1.05、冬 ×0.90），仅在倍率 **> 1.0** 时按已结算收益追加金币 / 灵石 / 经验（`SeasonService.getExplorationMultiplier`，夏 / 冬不加成也不倒扣，详见 [季节系统](../player/season)）；
3. **每日计数**：`DailyService.onExplore()` 累计当日游历次数并检查「今日机缘」；
4. **今日天象**：仅作用于机缘奖励结算（如游历满 3 次的机缘经验经天象修炼倍率放大），对事件本身收益**不生效**。

多数奖励以 `(境界编号 + 1) × N` 随境界缩放（境界编号：凡人 = 0 … 金仙 = 10，来自 `realm_config.json` 的 11 大境界索引）；随机区间均为左闭右开 `[a, b)`。游历事件中带物品掉落的分支会先经 `ItemRegistry.contains` 检查，未注册的物品自动回退为等值经验 / 灵石。
