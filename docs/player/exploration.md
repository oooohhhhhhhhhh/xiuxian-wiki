# 游历探索

游历（`/游历`）是玩家外出探索随机遭遇的系统，通过**权重抽奖**触发 13 种事件之一，获得经验、金币、灵石、物品等奖励（或遭遇战斗与陷阱损失）。

## 基础规则

| 项目 | 值 |
|------|------|
| 基础冷却 | **60 秒** |
| 巽风灵根（EXPLORATION_CD） | 冷却 -30% → **42 秒** |
| 重伤限制 | HP ≤ 0 无法游历 |
| 每日联动 | 每次游历计入「今日机缘·游历 3 次」进度 |

冷却公式：`有效冷却 = 60000ms × (1 - 灵根效果值)`，仅巽风灵根生效。

## 事件权重

13 种事件按权重抽奖（总权重 **152**）：

| 事件 | 权重 | 概率 |
|------|:---:|:---:|
| 遭遇妖兽（Monster） | 25 | 16.4% |
| 发现宝藏（Treasure） | 25 | 16.4% |
| 采集灵草（Herb） | 15 | 9.9% |
| 遇到修士（Cultivator） | 13 | 8.6% |
| 发现种子（Seed） | 12 | 7.9% |
| 采集材料（Material） | 10 | 6.6% |
| 偶遇游商（Merchant） | 10 | 6.6% |
| 发现遗迹（Ruins） | 10 | 6.6% |
| 神秘奇遇（Mystery） | 8 | 5.3% |
| 灵泉沐浴（SpiritSpring） | 8 | 5.3% |
| 遭遇陷阱（Trap） | 7 | 4.6% |
| 一无所获（Nothing） | 5 | 3.3% |
| 奇遇古塔（StrangeTower） | 4 | 2.6% |

> 奖励公式大多以 `(境界编号 + 1) × N` 随境界缩放（境界编号：凡人=0，金仙=10）。

## 事件奖励概览

| 事件 | 主要奖励 |
|------|------|
| 遭遇妖兽 | 完整回合制 PVE 战斗（30 回合上限），胜利得经验 / 金币 / 灵石 |
| 发现宝藏 | 金币 / 灵石（随境界缩放） |
| 采集灵草 | 灵草 / 回血丹 / 回蓝丹 / 灵泉水 1~2 个 |
| 遇到修士 | 50% 经验 / 30% 灵石 / 20% 赠物或金币 |
| 发现种子 | 种子 1~2 颗（普通 / 稀有 / 传说分层） |
| 采集材料 | 普通（50%）/ 稀有（35%）/ 史诗（15%）材料 1~3 个 |
| 偶遇游商 | 强化石 / 物品 / 金币 / 灵石 |
| 发现遗迹 | 宝物（40%）/ 灵石（35%）/ 经验（25%） |
| 神秘奇遇 | 传说材料 / 金币 / 经验 / 种子 / 灵石 |
| 灵泉沐浴 | 回复 25%~50% HP/MP + 灵泉水 1~3 个 |
| 遭遇陷阱 | 损失约 10%~22.5% 最大生命 |
| 一无所获 | 保底经验 |
| 奇遇古塔 | 天玉 / 渡劫丹 / 经验 / 强化石 / 灵石+金币 |

> 完整分支与数值见 [游历事件一览](./exploration-events)。
