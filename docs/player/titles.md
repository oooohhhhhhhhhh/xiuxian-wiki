# 称号系统

称号是玩家的荣誉标识，可提供**属性加成**（攻击 / 防御 / 生命 / 法力 / 速度 / 灵力 / 修炼速度 / 经验 / 掉落率）。称号定义集中在 `TitleRegistry`（`com.mtxgdn.game.title`），当前共 **19 个预设称号**。

## 稀有度

稀有度显示名由 `Title.getRarityLabel()` 定义：

| 稀有度 | 显示名 | 称号数 |
|--------|--------|:---:|
| COMMON | 普通 | 3 |
| UNCOMMON | 稀有 | 5 |
| RARE | 珍贵 | 5 |
| EPIC | 史诗 | 4 |
| LEGENDARY | 传说 | 2 |

## 称号属性

每个称号提供以下加成（数值见 [称号列表](./title-list)）：

- **固定属性**：攻击 / 防御 / 生命 / 法力 / 速度 / 灵力
- **百分比属性**：修炼速度加成、经验加成、掉落率加成

## 装备规则

- 同时只能装备 **1 个**称号，装备后立即生效，换装自动卸下旧称号（事务操作）
- 部分称号有**境界要求**（requiredRealm），未达境界无法获得
- 管理员可通过管理后台或 API 授予 / 撤销称号

## 获取途径

- 系统 / 活动奖励（如「副本征服者」为副本 Boss 最后一击奖励）
- 管理员授予（`grantTitle`）
- 部分称号由特定成就触发（如「开山祖师」创建宗门）

## QQ 指令

| 指令 | 说明 |
|------|------|
| `/称号` | 查看已拥有的称号 |
| `/称号 列表` | 浏览全部称号大全 |
| `/称号 装备 <名称>` | 装备称号 |
| `/称号 卸下` | 卸下称号 |
