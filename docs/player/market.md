# 坊市交易

坊市是玩家之间的物品交易市场，使用**灵石**结算。

## 交易规则

| 规则 | 说明 |
|------|------|
| 结算货币 | 灵石（跨等级自动支付并找零） |
| 手续费 | **5%**（`max(1, 价格×5%)`）；土金灵根（手续费减半）→ **2.5%** |
| 自买 | 禁止 |
| 撤单 | 物品退回背包，手续费不扣除（未预扣） |
| 挂单上限 | 无 |
| 过期 | 无（永久有效直到售出或撤单） |
| 列表显示 | `/坊市` 最多显示 15 条 |

## 流程

1. **上架**：`/上架 <物品> <数量> <灵石价格>`，物品立即从背包扣除
2. **购买**：`/购买 <挂单ID>`，支付灵石（卖家实收 = 价格 - 手续费）
3. **撤单**：`/撤单 <挂单ID>`，物品退回背包

## QQ 指令

| 指令 | 说明 |
|------|------|
| `/坊市` `/market` | 查看挂单（最多 15 条） |
| `/上架 <物品> <数量> <灵石>` `/list` | 上架物品 |
| `/购买 <挂单ID>` `/buy` | 购买物品 |
| `/撤单 <挂单ID>` `/cancel` | 撤单 |
| `/我的挂单` `/mylistings` | 查看我的挂单 |

## REST API

`GET /api/game/market`、`POST /api/game/market/list`、`POST /api/game/market/buy`、`POST /api/game/market/cancel`、`GET /api/game/market/my_listings`。
