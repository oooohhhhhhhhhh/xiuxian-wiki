# 坊市交易

坊市交易分为两块玩家间交易市场，统一使用**灵石**结算（跨等级自动支付并按低阶灵石找零）：

- **坊市挂单**：一口价长期挂单（`trade_listings` 表，模块 `trade`）
- **竞拍行**：限时竞价拍卖（`auction_listings` / `auction_bids` 表，属经济模块）

## 坊市挂单

### 交易规则

| 规则 | 说明 |
|------|------|
| 结算货币 | 灵石（跨等级自动支付找零） |
| 手续费 | 标价的 **5%**：`基础手续费 = ⌊标价 × 5%⌋，最低 1`；**土金灵根**（特效 `TRADE_FEE_HALF`）减半：`⌊标价 × 5%⌋ / 2，最低 1` |
| 手续费收取时机 | 成交时从**卖家所得**中扣除（上架时不预扣），买家实付 = 标价，卖家实收 = 标价 − 手续费 |
| 自买自卖 | 禁止 |
| 撤单 | 物品退回背包（未实际预扣手续费，无费用损失） |
| 到期 | 无（挂单长期有效直到售出或被撤） |
| 单笔限制 | 数量 ≤ **999,999**；标价 ≤ **999,999,999** 灵石 |
| 列表显示 | `/坊市` 最多显示 **15** 条 |

### 流程

1. **上架**：`/上架 <物品名或key> <数量> <灵石价格>`，物品立即从背包扣除，服务器记录手续费
2. **购买**：`/购买 <挂单ID>`，买家用灵石购买（事务内加锁防并发抢单），物品即时入买家背包，卖家收到扣除手续费后的灵石
3. **撤单**：`/撤单 <挂单ID>`，物品退回背包（仅限自己的挂单）

## 竞拍行

### 发布与竞价规则

| 规则 | 说明 |
|------|------|
| 拍卖时长 | **1 ~ 72 小时**，默认 **24** 小时（超出范围自动夹取） |
| 起拍价 | ≥ 1 灵石，上架即从背包扣除物品 |
| 手续费 | 成交价 **7%**：`max(1, 成交价 × 7%)`（`fee_rate = 0.07`），从卖家所得扣除；无灵根减免 |
| 出价 | 必须高于当前价至少 1 灵石；**不能竞拍自己的物品**；出价即从买家背包冻结灵石 |
| 被超价 | 原出价人冻结的灵石**即时原额退回**背包 |
| 结束结算 | 到期后查询时自动结算：最高出价者得物品，卖家收到 `成交价 − max(1, 成交价 × 7%)`；**无人出价则流拍**，物品退回卖家 |
| 自成交 | 禁止 |

### QQ 指令

| 指令 | 说明 |
|------|------|
| `/拍卖` | 查看竞拍列表（含剩余时间） |
| `/拍卖 出售 <物品> <数量> <起价> [小时]` | 上架竞拍 |
| `/拍卖 出价 <编号> <价格>` | 出价竞拍 |
| `/拍卖 我的` | 查看我发布的拍卖 |

### REST API

| 接口 | 方法 | 说明 |
|------|:---:|------|
| `/api/game/economy/auction/items` | GET | 在拍列表 |
| `/api/game/economy/auction/my` | GET | 我的拍卖 |

| `/api/game/economy/auction/bid` | POST（body：`listingId`、`amount`） | 出价 |
