# 宗门系统

宗门是玩家间的大型协作组织（数据表：`sects` / `sect_members` / `sect_applications` / `sect_warehouse` / `sect_wars`，模块 `sect`）。支持创建、申请加入、审批、5 级职位任命、捐献、仓库存取、升级、宗主转让、宗门战与解散，并拥有声望体系与排行。

## 创建宗门

| 条件 | 值 |
|------|------|
| 境界要求 | `realm ≥ 4`（常量 `MIN_LEVEL_CREATE = 4`） |
| 灵石消耗 | **500** 灵石（跨等级扣除） |
| 宗门名称 | 2~8 个字符，全服唯一 |
| 描述 | ≤ 100 字符，可省略 |
| 初始声望 | **1000** |
| 附加 | 创建者获得称号「开山祖师」（`sect_founder`），并以宗主身份入宗 |

> realm 编号 4 为**元婴期**：代码注释、常量说明与游戏内创建/转让提示文案均已统一为「元婴期以上」（门槛 `realm ≥ 4` 不变）。

## 加入与审批

- 已入宗者不可再申请；目标宗门满员（按成员上限）不可申请；同一宗门 pending 申请去重
- 审批权限：宗主 / 副宗主 / 长老（`canManage()`）；通过后新成员一律为**外门弟子**，并获得称号「首席弟子」（`senior_disciple`，仅首次入宗）

## 职位体系（5 级）

| 职位（内部值） | 管理权限 | 说明 |
|------|:---:|------|
| 宗主（LEADER） | ✅ | 全部：升级、宣战、转让、解散、踢副宗主、任命所有职位 |
| 副宗主（VICE_LEADER） | ✅ | 审批、踢长老及以下、任命长老及以下（**不能**任命/改动副宗主） |
| 长老（ELDER） | ✅ | 审批、踢内门/外门、仅能任命内门弟子/外门弟子 |
| 内门弟子（INNER_MEMBER） | ❌ | 可捐献、可消耗贡献值取仓库物品 |
| 外门弟子（OUTER_MEMBER） | ❌ | 同上（新成员默认职位） |

- 踢出 / 任命只能操作**职位比自己低**的成员（`canKickOrAppoint`：rank 数字越大职位越低）
- 宗主职位不可被踢出/改变；仅宗主可踢出或改动副宗主
- 踢人 / 查看申请列表等提示文案已统一为「宗主、副宗主和长老」（与 `canManage()` 管理权限一致）

## 成员上限与升级

```
成员上限 = 20 + (等级 - 1) × 5      # 1 级 20 人 → 10 级 65 人
升级消耗 = 当前等级 × 1000 声望     # 1→2 需 1000，9→10 需 9000
最高等级 = 10
```

- 升级仅宗主可操作，消耗宗门声望并同步成员上限

## 捐献与仓库

- **捐献**：任何成员可向仓库捐献物品（同物品自动合并）。普通弟子每个物品得 `max(2, ⌊物品价格 / 10⌋)` 贡献值；管理职位（宗主/副宗主/长老）捐献**不再获得贡献值**（防「免费取物 → 捐献」刷贡献循环）
- 任何成员捐献均使宗门声望 `+max(1, ⌊数量 / 10⌋)`
- **取出**：管理职位免费；内门/外门弟子消耗贡献值，每件成本 `max(10, ⌊物品价格 / 5⌋)`（高于捐献所得，杜绝套利）
- 解散宗门或宗主退出解散时，仓库物品**不返还**成员

## 宗主转让

| 条件 | 值 |
|------|------|
| 发起者 | 现任宗主 |
| 接收者 | 本宗成员、非宗主、`realm ≥ 4`（同创建门槛） |
| 消耗 | **200** 灵石（由宗主支付） |
| 结果 | 新宗主上任，原宗主降为**副宗主** |

## 宗门战

宗主对宗主宣战（无实验开关限制）：

| 条件 | 值 |
|------|------|
| 消耗 | **1000** 宗门声望 + **300** 灵石（宣战时即扣除） |
| 冷却 | 同一防守宗门 24 小时内只能被宣战一次 |
| 出战 | 双方各派 **5** 名最强弟子（按境界降序、同级按等级降序），逐对 1v1 模拟战斗 |
| 赛制 | 总场数 = min(双方出战人数)；先手按速度，回合上限 15，每回合先结算灵根再生 |
| 伤害 | `攻击 × 灵根增伤(SKILL_DAMAGE / DAMAGE_BOOST) × 暴击(基础 5%，倍率 1.5，可叠加) ± 随机 5 − 防御/3`，防御方灵根减伤 |
| 胜负 | 胜场多者胜；**平局判守方胜**；15 回合未分胜负按剩余 HP 百分比 |
| 奖惩 | 胜方 +**500** 声望；败方 −**500**（下限 0）；战报入库 `sect_wars` |

## 退出与解散

- 普通成员退出：直接生效，无惩罚
- 宗主退出：宗门还有其他成员时必须先转让或解散；若只剩自己，退出即解散宗门
- 解散：仅宗主，仓库/申请/成员记录一并清除

## 声望来源与消耗

| 方向 | 途径 |
|------|------|
| 获得 | 创建初始 +1000；成员捐献（小额）；宗门战胜 +500（服务层另有 `addContribution` 同步增加） |
| 消耗 | 宗门升级（等级 × 1000）；宣战 1000；宗门战败方 −500 |

## 排行

按声望降序（`/宗门 top` 与 REST 均取前 10），同声望时其次按等级（宗门列表 `list` 排序为声望 DESC、等级 DESC）。

## 指令入口

- QQ 主命令：`/宗门`（别名 `/sect`，权限码 `game.sect.manage`）；无参数显示本人宗门概览

| 子命令（中文 / 英文） | 说明 | 附加要求 |
|------|------|------|
| `create <名称> [描述]` / `创建` | 创建宗门 | 元婴期(代码 realm≥4) + 500 灵石 |
| `join <宗门名>` / `加入`、`apply <宗门名>` / `申请` | 申请加入 | 未入宗 |
| `list` / `列表`、`info [名称]` / `信息`、`members` / `成员` | 查询 | - |
| `pending` / `申请列表` | 待处理申请 | 管理职位 |
| `approve <玩家名>` / `通过`、`reject <玩家名>` / `拒绝` | 审批申请 | 管理职位 |
| `kick <玩家名>` / `踢出` | 踢出成员 | 管理职位、只能踢更低职位 |
| `appoint <玩家名> <副宗主\|长老\|内门弟子\|外门弟子>` / `任命` | 任命职位 | 管理职位、受职位限制 |
| `donate <物品key> <数量>` / `捐献` | 捐献仓库 | 任何成员（权限码 `game.sect.donate`） |
| `warehouse` / `仓库`、`take <物品key> <数量>` / `取出` | 仓库查看 / 取出 | 取出权限码 `game.sect.warehouse` |
| `levelup` / `升级` | 升级宗门 | 宗主 |
| `transfer <玩家名>` / `转让` | 宗主转让 | 宗主 + 200 灵石 |
| `war <宗门名>` / `宣战` | 宗门战宣战 | 宗主 + 1000 声望 + 300 灵石 |
| `disband` / `解散` | 解散宗门 | 宗主 |
| `leave` / `退出` | 退出宗门 | - |
| `top` / `排行` | 声望排行 | - |

### REST / WebSocket

- REST（权限码 `game.sect.manage`，捐献/取出另用 `game.sect.donate` / `game.sect.warehouse`）：`GET/POST /api/game/sect/*`，含 `sect/list`、`sect/info[/{sectId}]`、`sect/members`、`sect/create`、`sect/join/{sectId}`、`sect/applications`、`sect/approve|reject/{appId}`、`sect/leave`、`sect/kick/{targetPlayerId}`、`sect/appoint`、`sect/warehouse`、`sect/donate`、`sect/take`、`sect/disband`、`sect/levelup`、`sect/transfer/{targetPlayerId}`、`sect/war/{targetSectId}`、`sect/top`；`/sect/list|info` 亦注册于统一指令分发
- WebSocket 动作：`sect_list`、`sect_info`、`sect_members`、`sect_create`、`sect_join`、`sect_applications`、`sect_approve`、`sect_reject`、`sect_leave`、`sect_kick`、`sect_appoint`、`sect_warehouse`、`sect_donate`、`sect_take`、`sect_disband`、`sect_levelup`、`sect_transfer`、`sect_war`、`sect_top`（模块门控 `sect`）
