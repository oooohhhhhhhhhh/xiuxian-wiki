# 宗门系统

宗门是玩家间的大型协作组织。可创建 / 申请加入 / 审批 / 任命 / 捐献 / 仓库存取 / 升级 / 宗主转让 / 宗门战 / 解散，拥有 5 级职位体系与声望排行。

## 创建宗门

| 条件 | 值 |
|------|------|
| 境界要求 | realm ≥ 4（代码常量 `MIN_LEVEL_CREATE=4`；按境界表为**元婴期**，但游戏内提示文案写「金丹期以上」，存在常量与文案不一致） |
| 灵石消耗 | **500** 灵石 |
| 宗门名称 | 2~8 个字符（唯一） |
| 描述 | ≤ 100 字符，可省略 |

## 职位体系（5 级）

| 职位 | 管理权限 | 说明 |
|------|:---:|------|
| 宗主 | ✅ | 全部权限（升级 / 宣战 / 转让 / 解散） |
| 副宗主 | ✅ | 审批、踢人、任命长老及以下（不能任命副宗主） |
| 长老 | ✅ | 审批、踢人、任命仅内门 / 外门 |
| 内门弟子 | ❌ | 可捐献、可消耗贡献值取仓库物品 |
| 外门弟子 | ❌ | 同上 |

- 新成员加入一律为**外门弟子**；只有宗主能改变副宗主职位
- 踢人 / 任命只能操作**职位比自己低**的成员
- 权限校验以代码 `canManage()`（宗主 / 副宗主 / 长老）为准，踢人提示文案「只有宗主和长老才能踢人」与实现不符（副宗主也能踢）

## 成员上限与升级

```
成员上限 = 20 + (等级 - 1) × 5      # 1 级 20 人 → 10 级 65 人
升级消耗 = 当前等级 × 1000 声望     # 1→2 级需 1000，9→10 级需 9000
最高等级 = 10
```

升级仅宗主可操作，消耗宗门声望。

## 捐献与仓库

- **捐献**：任何成员可向仓库捐献物品（同物品自动合并）；**普通弟子每个物品 +10 贡献值**，管理职位捐献**不加贡献值**（防刷设计）
- **取出**：宗主 / 副宗主 / 长老**免费**取出；内门 / 外门需消耗贡献值：`贡献成本 = max(50, 物品价格 / 10)` 每件
- 解散宗门时仓库物品**不返还**成员

## 宗主转让

| 条件 | 值 |
|------|------|
| 发起者 | 现任宗主 |
| 接收者 | 本宗成员、非宗主、realm ≥ 4 |
| 消耗 | **200 灵石**（宗主支付） |
| 结果 | 新宗主上任；**旧宗主降为副宗主** |

## 宗门战

宗主对宗主宣战：

| 条件 | 值 |
|------|------|
| 消耗 | 1000 宗门声望 + 300 灵石 |
| 出战 | 双方各派 5 名最强弟子（境界 → 等级排序） |
| 赛制 | 逐对 1v1 模拟战斗（复用灵根特效：暴击 / 增伤 / 减伤 / 再生） |
| 胜负 | 胜方 +500 声望；败方 -500 声望（下限 0）；**平局判守方胜** |
| 战报 | 自动入库 `sect_wars`，无冷却限制 |

模拟战斗规则（`simulateDuel`）：先手按速度；回合上限 15；每回合先结算灵根再生；伤害 = 攻击 × 灵根增伤 × 暴击（基础 5%，灵根可提升；暴击倍率 1.5 基础）± 随机 5 点 - 防御 / 3；防御方灵根减伤；HP 归零即败，15 回合后按 HP 百分比决胜。

## 退出与解散

- 普通成员退出：直接退出，**无惩罚**
- 宗主退出：若宗门还有其他成员则必须**先转让或解散**；若只剩自己则退出即解散
- 解散：仅宗主，仓库物品不返还

## 宗门排行

按**声望**降序（其次等级），`/宗门 top` 与 REST 取前 10。

## QQ 指令

| 指令 | 说明 |
|------|------|
| `/宗门` | 无参数显示本人宗门概览 |
| `/宗门 create <名称> [描述]` | 创建宗门 |
| `/宗门 join <宗门名>` / `apply` | 申请加入 |
| `/宗门 list` / `info [名称]` / `members` | 查询 |
| `/宗门 approve <玩家名>` / `reject <玩家名>` / `pending` | 审批（宗主/副宗主/长老） |
| `/宗门 kick <玩家名>` | 踢出成员 |
| `/宗门 appoint <玩家名> <副宗主\|长老\|内门弟子\|外门弟子>` | 任命职位 |
| `/宗门 donate <key> <数量>` | 捐献物品 |
| `/宗门 warehouse` / `take <key> <数量>` | 仓库查看 / 取出 |
| `/宗门 levelup` | 宗门升级（宗主） |
| `/宗门 transfer <玩家名>` | 宗主转让（200 灵石） |
| `/宗门 war <宗门名>` | 宗门战宣战（1000 声望 + 300 灵石） |
| `/宗门 disband` | 解散宗门（宗主） |
| `/宗门 top` | 声望排行 |
