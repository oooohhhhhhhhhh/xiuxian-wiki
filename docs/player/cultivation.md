# 修炼系统

修炼（打坐 / 闭关）是获取经验（灵力）的核心途径。开始修炼后经验按秒积累，停止时结算并结算心魔判定；玩家离线时修炼仍以 50% 效率继续（详见 [离线收益](#离线收益)）。

## 修炼方式

| 方式 | 说明 |
|------|------|
| 打坐 / 闭关 | `/打坐` 开始，`/停止` 结束并结算 |
| 离线修炼 | 下线后继续（50% 效率，上限 8 小时），上线自动结算 |
| 洞府冥想 | 在洞府内冥想，固定获得经验并附带洞府修炼加成 |
| 灵石加速 | `/修炼加速 <灵石>` 燃烧灵石临时加速（每 100 灵石 = 1 小时 ×1.5 倍） |

## 经验公式

```
每秒经验 = max(1, round( 境界倍率 × 1 × 季节倍率 × 地点灵气倍率 ))

总经验   = round( 每秒经验 × 修炼秒数 )
```

| 因子 | 说明 |
|------|------|
| 境界倍率 | 由 `realm_config.json` 定义：凡人 1.0 / 炼气 1.5 / 筑基 2.0 / 金丹 3.0 / 元婴 5.0 / 化神 8.0 / 合体 12.0 / 大乘 20.0 / 渡劫 24.0 / 真仙 28.0 / 金仙 35.0 |
| 季节倍率 | 春 ×1.10 / 夏 ×1.05 / 秋 ×1.15 / 冬 ×0.95（[季节系统](./season)） |
| 地点灵气 | 当前所在地点的修炼灵气加成（[世界地图](./map)，1.00~1.50） |
| 灵根效率 | 木水灵根（CULTIVATION_EFFICIENCY +15%）仅在**离线结算**路径生效 |

> 注意：功法的修炼速度加成、称号的修炼速度加成当前**未接入**修炼经验公式（仅展示）。

## 修炼规则

- **重伤不可修炼**（HP ≤ 0 时被拦截）
- 重复开始修炼会被拒绝；开始修炼会清除离线时间戳
- 停止修炼时先做**心魔判定**，再按净收益发放经验
- 经验通过 `addExperience` 发放，会吃**称号经验加成**

## 心魔系统

停止修炼（或离线结算）时，按修炼时长触发心魔判定，修为倒退。

```
基础触发率 = 8% × 修炼小时数
灵力抵抗   = min(8%, 灵力 / 15)            # 每 15 点灵力 -1%，上限 -8%
灵根抵抗   = 按品级：鸿蒙 8 / 正·五行 6 / 异灵根 4 / 天灵根 3 / 双灵根 2 / 三灵根 1 / 四象 0 / 混沌 -2
洞府抵抗   = 洞府等级 × 3%（在洞府修炼时）
最终触发率 = clamp(基础 - 灵力 - 灵根 - 洞府, 0, 40%)
```

**心魔程度**（触发后随机）：

| 程度 | 概率 | 经验损失 |
|------|:---:|----------|
| 轻微 | 50% | 本次修炼所得的 20%~40% |
| 中等 | 35% | 50%~70% |
| 严重 | 15% | 80%~100% |

> 混沌灵根（大器晚成）在觉醒后灵根抵抗 +2%（抵消杂灵根 -2% 的劣势）。

## 离线收益

| 参数 | 值 |
|------|------|
| 离线修炼效率 | **50%**（在线的一半） |
| 最大离线时长 | **8 小时**（超过不计） |
| 最短触发 | 30 秒（短暂断线不触发） |
| HP / MP 恢复 | 每分钟 2%，至满 |
| 离线心魔频率 | 在线模式的 **50%** |
| 天象加成 | ✅ 生效 |
| 灵根效率 | ✅ 木水灵根 +15% |

结算时机：WebSocket 认证成功、`GET /api/game/player`、`/状态` 等查询时自动结算；结算后若原本在闭关会自动重新开始闭关。

## 灵石加速修炼

- 每 **100 下品灵石** = 1 小时加速，倍率 **×1.5**
- 必须**正在闭关**、至少有 100 灵石
- 奖励经验 = 每秒经验（仅境界倍率）× 小时数 × 3600 × 0.5，直接发放
