# 修炼系统

打坐 / 闭关（统称修炼）是获取修为（经验）的核心途径：开始后系统按秒累计，停止时统一结算，并按结算额做**心魔判定**；玩家离线时若正在闭关，修炼以 **50% 效率**继续至多 **8 小时**，上线自动结算。修炼相关指令/服务集中在 `PlayerService`、`OfflineRewardService`、`HeartDemonService`、`SeasonService` 与修炼模块指令中。

## 修炼方式

| 方式 | 入口 | 说明 |
|------|------|------|
| 打坐 / 闭关 | `/打坐`（`/闭关`、`/meditate`、`/cultivate`） | 开始修炼，回显「每分钟约 X 灵力」及季节/地点倍率 |
| 停止结算 | `/停止`（`/stop`） | 结束修炼：先心魔判定，再按净收益发经验 |
| 离线修炼 | 自动 | 闭关中下线即续修（50% 效率、上限 8 小时），上线/查状态时结算 |
| 灵石加速 | `/修炼加速 <灵石数>`（`/boost`） | 燃烧灵石立即获得一次性加速经验（须先处于修炼状态） |
| 晨修 | `/晨修`（`/morning`） | 每日 5:00–11:00 的一次性高收益修炼（含天象/季节加成与连续加成） |
| 洞府冥想 | 洞府系统 | 洞府内冥想有独立加成，且心魔判定带洞府等级抵抗（详见 [洞府系统](../player/cave)） |

## 开始 / 停止规则（`PlayerService`）

- **重伤不可修炼**：`hp <= 0` 时 `/打坐` 被拦截（提示先疗伤）；
- 已在闭关中重复开始会被拒绝；成功开始时清零离线时间戳；
- 停止使用**原子条件更新**（`AND is_cultivating = 1`）：并发多次停止只有第一次能结算成功，防止经验重复发放；
- 停止结算的净收益经验经 `addExperience` 发放，该入口会叠乘**称号经验加成**与**经验类 Buff 倍率**（`BuffService.getExpMultiplier`）。

## 修炼倍率公式（代码）

`PlayerService.cultivationMultiplier` 全程以 double 累乘，开始/停止分别用于展示与结算（结算最后一次性 `Math.round`，避免逐秒取整吞掉小数倍率）：

```
修炼总倍率 = 境界基础(大境界倍率 × baseValue=1)
          × 季节倍率            SeasonService.getCultivationMultiplier()
          × 地点灵气倍率        MapService.getCultivationBonus(当前地点)
          × 灵根效率           木水灵根 CULTIVATION_EFFICIENCY → ×(1+0.15)
          × 天象修炼倍率       今日天象 cultivationMultiplier（见下表）
          × 功法修炼速度       已装备功法 cultivation_speed_bonus 之和 → ×(1+Σ)
          × 称号修炼速度       装备称号 cultivationSpeedBonus → (1+加成)
          × 阵法加成           ×(1 + 阵法总修炼加成/100)

每秒经验（展示） = max(1, round(总倍率))
结算经验         = round(总倍率 × 修炼秒数)
```

| 因子 | 说明 |
|------|------|
| 境界基础 | `realm_config.json` 的 `cultivationPerSecond`：baseValue=1，大境界倍率 凡人1.0 / 炼气1.5 / 筑基2.5 / 金丹4.0 / 元婴6.0 / 化神10.0 / 合体18.0 / 大乘32.0 / 渡劫55.0 / 真仙90.0 / 金仙150.0 |
| 季节倍率 | 春 ×1.10 / 夏 ×1.05 / 秋 ×1.15 / 冬 ×0.95（`SeasonService`，全服共享，calendar/cycle 两种模式） |
| 地点灵气 | 由玩家当前所在地点决定（世界地图地点配置，见 [世界地图](../player/map)） |
| 天象倍率 | 见下方「每日天象」表，仅紫气东来/万籁俱寂对修炼有增益 |
| 功法 / 称号 / 阵法 | 已装备功法的修炼速度加成之和、装备称号的修炼速度加成、阵法（聚灵阵等）修炼加成——三者均已接入结算 |

## 离线收益（`OfflineRewardService`）

| 参数 | 值 |
|------|------|
| 离线修炼效率 | **50%**（在线的一半） |
| 最大离线时长 | **8 小时**（超过不计） |
| 最短结算时长 | **30 秒**（低于视为短暂断线，清空时间戳不结算） |
| HP / MP 恢复 | 每分钟恢复最大值的 **2%**，至满 |
| 心魔判定频率 | 按离线时长 **×0.5** 折算（离线 1 小时等效 0.5 小时修炼时长参与心魔判定） |
| 结算后 | 若原本在闭关，结算完成后**自动重新开始闭关** |

离线结算公式（代码现状）：

```
离线经验 = calculateCultivationExp(玩家, 离线秒) × 0.5     // 基础倍率与在线一致（境界/季节/地点/灵根/功法/称号/阵法已含）
        × 今日天象倍率 × (1 + 木水灵根 0.15)              // 离线路径对天象与灵根效率各再乘一次（源码现状）
净经验   = 离线经验 经心魔判定后的净值（触发心魔则扣损）
```

> 触发时机：WebSocket 认证欢迎帧（`GameWebSocketApp`）、`GET /api/game/player`、OneBot / QQ 官方机器人收到绑定账号消息、`/状态` 查询时自动结算；`last_offline_time` 在 WebSocket 断开（`onClose`）时写入。结算采用「原子认领」防并发重复发放。

## 心魔系统（`HeartDemonService`）

停止修炼或离线结算时，按结算时长做一次心魔判定，触发则本次所得修为**按程度倒扣**：

```
基础触发率   = 8% × 修炼小时数
灵力抵抗     = min(8%, 神识/15)                 // 每 15 点神识 -1%，上限 -8%
灵根抵抗     = 按品级：鸿蒙 8 / 正·五行 6 / 异灵根 4 / 天灵根 3
               / 双灵根 2 / 三灵根 1 / 四象 0 / 杂灵根 -2
               （混沌灵根另因 LATE_BLOOMER 额外 +2 → 净 0）
洞府抵抗     = 洞府等级 × 3%（洞府冥想结算时）
最终触发率   = clamp(基础 - 灵力 - 灵根 - 洞府, 0, 40%)
```

**心魔程度**（触发后随机）：

| 程度 | 概率 | 经验损失 |
|------|:---:|----------|
| 轻微 | 50%（roll < 50） | 本次结算所得的 20%~40% |
| 中等 | 35%（roll < 85） | 50%~70% |
| 严重 | 15%（其余） | 80%~100%（损失至少 1 点） |

> 源码校正：混沌灵根的 +2 心魔抵抗是**无条件**生效（非旧文档所称「觉醒后才 +2」），用于抵消杂灵根品级自带的 -2，最终净抵抗为 0。

## 灵石加速修炼（`EconomyService.boostCultivation`）

- 前置：**必须先开始修炼**（`/打坐`），且每次至少 **100 灵石**；
- 每 **100 灵石 = 1 小时**（向下取整，只收取整百部分）；
- 立即获得额外经验：`normalExp = (int)(境界每秒基础经验) × 小时 × 3600`，`额外经验 = normalExp × (1.5 - 1)`（即约 ×1.5 的额外部分），经 `addExperience` 发放（同样吃称号/经验 Buff 加成）；
- 境界每秒基础经验 = `GameConfigLoader.getCultivationPerSecond(realm)`（仅大境界倍率，整数截断，不叠加季节/地点等倍率）。

## 晨修（`MorningCommand` / `DailyService.doMorningCultivation`）

- 时段：**每日 5:00–11:00**（卯时至巳时，`hour >= 5 && hour < 11`），每日一次；
- 连续天数：与昨日连续则 `consecutive+1`，否则从 1 重新计；
- 经验公式：`base = (境界id+1) × 50`；`bonus = base × (连续天数-1) × 10%`；再依次叠乘天象修炼倍率、木水灵根 +15%、季节加成（`季节修炼倍率-1` 的增量）后发放；
- 灵石公式：`(境界id+1) × 10` 依次叠乘天象灵石倍率、火土木灵根 +20%、季节灵石倍率；
- 晨修同时推进「累计活跃天数」，触发 **灵根共鸣** 里程碑（7/30 天，见 [灵根系统](./spiritual-root)）；
- 指令权限 `game.player.info`，所属模块 `cultivation`。
