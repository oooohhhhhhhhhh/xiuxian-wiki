# 功法系统

功法是永久习得、按需「运转」的成长系统：学习后获得一门功法，**最多同时装备（运转）3 门**；装备后功法把自身六维属性加成直接叠加到角色属性上，卸下时严格回退。内置 **15 门默认功法**，由 `TechniqueService.insertDefaultTechniques` 在启动时按名称幂等写入 `techniques` 表（`data/mtxgdn` 无功法类，功法即数据库内置数据），分 修炼 / 攻击 / 防御 / 辅助 4 种类型。

## 功法类型（`Technique.Type`）

| 类型 | 定位 |
|------|------|
| 修炼（`CULTIVATION`） | 修炼速度 / 经验方向（6 门） |
| 攻击（`ATTACK`） | 攻击、技能伤害方向（4 门） |
| 防御（`DEFENSE`） | 生命、防御、减伤方向（4 门） |
| 辅助（`UTILITY`） | 综合增益（1 门：太虚经） |

## 加成与成长公式

- **数值类加成**（生命/法力/攻击/防御/速度/神识）：`加成 = 基础值 + (int)(基础值 × (等级-1) × 0.12)`（每级按基础的 12% 线性成长，向下取整）；
- **百分比类加成**（修炼速度/经验/战斗伤害/减伤）：`加成 = 基础 × (1 + (等级-1) × 0.08)`（每级相对基础 +8%）；
- 太虚经满级 8，其余默认功法满级 10。

## 学习 / 装备 / 卸下 / 升级（`TechniqueService`）

| 操作 | 规则 |
|------|------|
| 学习 | 校验已学 / 境界（`player.realm >= requiredRealm`）/ 金币 / 灵石 → 扣费习得 **Lv.1**。**学习本身不增加属性**（源码注释：属性只在「装备」时生效，避免重复叠加），提示「装备后获得属性加成」 |
| 装备 | 已学且未运转；**最多同时装备 3 门**（`MAX_EQUIPPED = 3`）；装备时把该功法按当前等级的加成叠加到角色属性（生命/法力/攻击/防御/速度/神识，HP/MP 同步抬上限并补足） |
| 卸下 | 停止运转并按装备时同款公式**严格回退**属性（与装备互逆，杜绝反复装卸刷属性） |
| 升级 | 消耗 `升级基准费用 × 当前等级`（金币 + 灵石），等级 +1 且熟练度清零；若该功法正在运转，先按旧等级回退、再按新等级施加（补差） |
| 熟练度 | `players_techniques` 表有熟练度字段与 `addProficiency` 接口（当前无自动增长来源） |

## 修炼与战斗中的实际作用（源码现状）

| 效果字段 | 是否接入 | 说明 |
|------|:---:|------|
| 修炼速度（`cultivation_speed_bonus`） | ✅ 已接入 | 已装备功法的成长后加成之和，在修炼结算中作为 `×(1 + Σ)`（`PlayerService.cultivationMultiplier`） |
| 六维属性加成 | ✅ 已接入 | 装备/卸下时直接读写角色属性 |
| 经验（`exp_bonus`） | ✅ 已接入 | 已装备功法的成长后加成之和并入 `PlayerService.getFinalExpBonus`，由 `addExperience` 统一乘算——修炼、晨修、机缘、PVE/PVP/秘境与离线收益全链路生效（同一经验入口与称号/丹药经验倍率叠加） |
| 战斗伤害（`combat_damage_bonus`） | ✅ 已接入 | 战斗开始时读取已装备功法加成之和，对 PVE / PVP / 团队 Boss 的每次命中按 `×(1 + Σ)` 加成（`CombatService`，战前一次取齐避免每回合查库） |
| 减伤（`damage_reduction`） | ✅ 已接入 | 战斗开始时读取已装备功法减伤之和，对 PVE / PVP / 团队 Boss 中受到的伤害按 `×(1 − Σ)` 削减（与技能减伤、阵法防御加成叠乘） |

## QQ / REST 指令

| 入口 | 说明 |
|------|------|
| `/功法`、`/technique`、`/tj` | 功法系统主指令（分类「战斗」，模块 `technique`，无权限码） |
| `/功法 列表`（`list`） | 功法大全 |
| `/功法 我的`（`my`/`mine`） | 已学功法及等级（含「最多同时装备3门」提示） |
| `/功法 学习 <ID>`（`learn`） | 学习功法 |
| `/功法 装备 <ID>`（`equip`） | 运转功法（最多 3 门） |
| `/功法 卸下 <ID>`（`unequip`/`uninstall`） | 停止运转 |
| `/功法 升级 <ID>`（`upgrade`） | 升级功法 |
| REST | `GET /game/technique/list`、`GET /game/technique/my`、`POST /game/technique/learn\|equip\|unequip\|upgrade`（双端同逻辑） |
