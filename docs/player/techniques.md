# 功法系统

功法（心法）是永久性成长系统：学习后获得**属性加成**，最多同时**运转 3 门**，可花钱升级。共 **11 种功法、4 种类型**（由 `TechniqueService.insertDefaultTechniques` 初始化）。

## 加成公式

```
属性类加成（HP/MP/攻/防/速/灵力）= 基础 + (int)(基础 × (等级-1) × 0.12)    # 每级 +12%
百分比类加成（修炼速度/经验/伤害/减伤）= 基础 × (1 + (等级-1) × 0.08)      # 每级 +8%
```

## 学习 / 装备 / 升级

| 操作 | 规则 |
|------|------|
| 学习 | 校验境界 / 金币 / 灵石，扣费后习得 Lv.1，**学习时立即获得属性加成** |
| 装备 | 最多同时运转 **3 门**（`MAX_EQUIPPED=3`）；装备后再次应用属性加成 |
| 卸下 | 停止运转（属性加成不扣除） |
| 升级 | `升级费用 = 升级基准 × 当前等级`（金币 + 灵石），最高 10 级（太虚经 8 级） |

> 说明（源码现状）：功法的「战斗伤害 / 减伤」加成（如锐金诀 +3% 伤害、铁骨功 3% 减伤）目前**仅展示、未接入战斗计算**；学习时即加属性、卸下不还原的机制与直觉不同，属现有实现。
