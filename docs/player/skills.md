# 技能系统

技能是角色在回合制战斗中的主动手段（攻击 / 治疗 / 防御护体三类）。启动时 `SkillService.insertDefaultSkills` 向 `skills` 表写入 **15 个默认技能**（含 9 个基础技能与 6 个合体期以上高阶技能），玩家通过 `/学习` 手动学习（按技能自身境界要求与费用），战斗中每释放一次获得熟练度，熟练度可自动升段也可手动升级；另有技能书（秘籍）道具可「参悟」直升等级。技能数据表 `players_skills` 记录玩家已学技能（等级 / 熟练度）。

## 学习技能（`SkillService.learnSkill`）

- 校验：未学过 → 境界达标（`player.realm >= requiredRealm`）→ 金币/灵石足够；
- 成功：扣费，习得 **Lv.1、熟练度 0**；
- 学习计入「今日机缘·学技能」进度（`DailyService.onSkillLearn`），并**首次学会任意技能授予称号「剑道学徒」**（`sword_student`）；
- 境界配置中的 `unlockSkillId`（见 [境界一览](./realm-list)）仅随突破结果返回，**技能始终需要 `/学习` 手动学习**，门槛以技能自身 `required_realm` 为准。

## 熟练度与升级

**熟练度来源**：每场战斗（PVE 游历/秘境、PVP 切磋、组队 Boss 战）结束后，按本场**实际释放过的技能**逐个 **+15 熟练度**（`CombatService.addSkillProficiency`，胜负双方均计）；**金水木灵根**（`PROFICIENCY_BOOST` +30%）使每次到账的熟练度 ×1.3（`SkillService.addProficiency`）。

**自动升级**（战斗结算 `addProficiency` 内循环处理）：

```
升到下一级所需熟练度 = 当前等级 × 100     （Lv1→2 需 100，Lv2→3 需 200，…）
熟练度足够则连续升级，扣除相应熟练度，直到不足或满级
```

**手动升级**（`/技能 升级 <技能ID>`，`SkillsCommand`）：消耗 `100 × (当前等级+1)` 熟练度直接升 1 级，其余熟练度保留。

## 战斗中技能效果（`CombatService`）

```
技能伤害 = 基础伤害 + (int)(基础伤害 × (等级-1) × 0.15)      // 每级 +15%
技能治疗 = 基础治疗 + (int)(基础治疗 × (等级-1) × 0.15)
技能法力 = 基础法力 + (int)(基础法力 × (等级-1) × 0.15)
```

- 玄冰灵根 `SKILL_DAMAGE` +15%：技能伤害再 ×(1+0.15)；
- 玄冥水灵根 `MP_COST_REDUCTION` -20%：技能法力消耗按效果值降低；
- 每场战斗按技能**回合冷却**（SkillCooldown）与当前法力决定施放；
- **战斗策略**影响技能取舍：法力低于预留线（防守策略保留更多法力）时不出技能改普攻；攻击技能按伤害从高到低选择当前可用者，治疗/护体技能按需施放。

## 技能书（秘籍道具）

技能书为 `SKILL_BOOK` 类型物品，使用（参悟）后：**未学会 → 习得 Lv.1；已学会 → 等级 +1（至满级为止）**（`SkillService.learnSkillFromBook`）。内置技能书：

| 物品（key） | 稀有度 | 对应技能 |
|------|:---:|------|
| 基础剑谱（`mtxgdn:basic_sword_manual`） | 普通 COMMON | 基础剑诀（ID 9） |
| 火龙诀（`mtxgdn:fire_dragon_art`） | 史诗 EPIC | 天雷咒（ID 3） |

## QQ 指令

| 指令 | 说明 |
|------|------|
| `/技能`（`/skills`） | 查看技能库（含境界要求与金币费用），子命令 `升级`：`/技能 升级 <技能ID>`（分类「战斗」，模块 `skill`，权限 `game.player.info`） |
| `/学习 <技能ID或名称>`（`/learn`） | 学习指定技能（支持 ID 或名称模糊匹配；权限 `game.skill.learn`，模块 `skill`） |
