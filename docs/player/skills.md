# 技能系统

技能提供战斗中的主动攻击手段，通过**熟练度**升级（也可用技能书直升）。共 **9 种技能**，由 `SkillService.insertDefaultSkills` 初始化。

## 学习

- 校验境界（`required_realm`）、金币、灵石，扣费后习得 **Lv.1**
- 学习技能计入「今日机缘·学技能 1 次」进度

### 技能书

| 物品 | 对应技能 |
|------|------|
| 基础剑谱（basic_sword_manual） | 基础剑诀（ID 9） |
| 火龙诀（fire_dragon_art） | 天雷咒（ID 3） |

技能书效果：已学会 → 技能等级 +1（上限满级）；未学会 → 学会 Lv.1。

## 熟练度与升级

- 战斗中使用过的技能每个 **+15 熟练度**（PVE / PVP 均生效，胜负都加）
- **金水木灵根**（PROFICIENCY_BOOST）：熟练度获取 **+30%**
- 自动升级需求：`当前等级 × 100`（Lv1→2 需 100，Lv2→3 需 200，…）
- 手动升级（`/技能 升级`）：消耗熟练度 `100 × (等级+1)`，直接升 1 级
- 满级 **10 级**

## 战斗中的技能效果

```
技能伤害 = 基础伤害 + (int)(基础伤害 × (等级-1) × 0.15)     # 每级 +15%
技能蓝耗 = 基础蓝耗 + (int)(基础蓝耗 × (等级-1) × 0.15)     # 每级 +15%
```

- 玄冰灵根（SKILL_DAMAGE）：技能伤害 +15%
- 玄冥水灵根（MP_COST_REDUCTION）：技能蓝耗 -20%
- 技能等级提升也受战斗策略影响（猛攻优先用最强技能，防守保留一半法力）
