# PVP 对战

PVP 是玩家之间的回合制切磋。挑战者发起挑战，被挑战者需在 30 秒内接受或拒绝（私聊通知），接受后自动战斗。

## 挑战流程

1. `/挑战 <角色名>` 发起挑战（不能挑战自己，双方需 HP > 0）
2. 被挑战者收到**私聊通知**，回复 `/挑战 接受` 或 `/挑战 拒绝`
3. 挑战超时 **30 秒**自动作废；发起者同时只能有一个未决挑战
4. 接受后立即开战并分段播报战报

> REST 接口 `POST /api/game/pvp/challenge` 直接发起并立即执行战斗（无待定 / 接受机制）。

## 战斗规则

- **先手**：挑战者速度 ≥ 被挑战者速度则挑战者先手
- **回合上限**：20 回合；超时按剩余 HP 判定（相同判平局）
- 每回合双方先结算灵根再生，先手方行动后后手方行动
- 技能自动施放，受**战斗策略**影响（见下）

## 伤害公式（玩家 → 玩家）

```
普攻伤害 = 最终攻击                       # PVP 普攻不含灵力（PVE 含）
技能伤害 = 基础伤害 × (1 + 15%×(等级-1)) × (1 + 玄冰技能伤害加成)
总伤害   = × (1 + 离火增伤) × 暴击倍率 + 随机(-5~+5) - 对方防御/3
暴击率   = 最终速度/200 + 太乙金灵根加成
暴击倍率 = 1.5 + 惊雷灵根加成
对方伤害 = × (1 - 厚土减伤 15%)
```

## 战斗策略

| 策略 | 效果 |
|------|------|
| 猛攻（aggressive） | 优先使用伤害最高的技能，全力输出 |
| 均衡（balanced，默认） | 按技能 ID 升序选择第一个可用技能 |
| 防守（defensive） | **保留一半法力**，蓝量低于一半时普攻 |

`/战斗策略 <猛攻|均衡|防守>` 设置，仅影响 PVP。

## 奖励

| 奖励 | 规则 |
|------|------|
| 经验（挑战者胜） | `50 + 败者等级×10`；若挑战者境界低于对手则 **×2**；+随机 0~30 |
| 金币（挑战者胜） | 随机 50~200 |
| 熟练度 | 双方战斗中使用的技能各 +15 |
| 每日机缘 | 计入「今日机缘·战斗 1 次」（奖励金币） |

奖励只结算**挑战者**视角。发起挑战无任何消耗；战后双方 HP 恢复至战前数值（战斗损耗不保留，属现有实现）。

## 组队系统

组队（`TeamService`）用于团队副本等玩法：

- 队伍 2~5 人（少于 2 人自动解散），纯内存存储（无数据库表）
- 队长创建 / 邀请，成员接受加入；队长离开即解散全队
- 组队本身**无属性加成**；团队秘境入口使用队伍成员列表
