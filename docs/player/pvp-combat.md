# PVP 对战

PVP 对战是玩家之间的**自动回合制切磋**：发起方先发出挑战，被挑战方在 **30 秒**内决定接受或拒绝，接受后立即开战并逐回合播报战报。PVP 属于内置玩法模块「战斗」（配置键 `built_in_plugins.pvp`，默认启用）。

## 挑战流程

1. 使用 `/挑战 <角色名>` 发起切磋（角色名需精确匹配；不能挑战自己）。
2. 服务端校验双方状态（详见下方「PVP 专属限制」），通过后向被挑战者发送**私聊通知**（QQ 群 / 私聊 / QQ 官方机器人渠道均可触达），提示其用 `/挑战 接受` 迎战或 `/挑战 拒绝` 回避。
3. 挑战等待被挑战者回应，**超时 30 秒自动作废**；发起方同时只能有一个未决挑战，同一被挑战者也只保留最近一次待处理挑战。
4. 被挑战者 `/挑战 接受` 后立即开始战斗，战报分段发送（回合分隔、每段约 5 行叙事）。

> `/挑战` 指令要求权限码 `game.pvp.challenge`（默认玩家角色持有）。
> 传统别名 `/决斗 <角色名>`、`/切磋`、`/pvp`、`/fight` 走同一套挑战（接受 / 拒绝）流程，但指令本身无权限码门控（见文末「兼容入口」）。

## 战斗规则

- **参战前提**：双方生命值都必须大于 0（重伤状态无法发起或应战）。
- **先手**：挑战者最终速度 ≥ 被挑战者最终速度则挑战者先手（同速挑战者先手）。
- **回合上限**：**20 回合**。回合耗尽仍未分出胜负时，按**剩余生命值高低**判定——剩余生命多者胜，完全相同则判**平局**。
- **每回合**：双方先各自结算灵根再生（青帝木灵根等每回合恢复 3% 最大生命），随后按先手次序各行动一次。
- **自动决策**（与 PVE 相同，详见 [PVE 战斗与 Boss](../player/pve-combat)）：
  - 生命 ≤ 50% 且法力足够时优先施放治疗技能；
  - 攻击技能选择受**战斗策略**影响（见下）；
  - 开局自动运转防御型技能（如金刚护体），本场减伤最高 30%；
  - 反弹类 Buff 会把受到的伤害反弹给攻击方；
  - 同一技能两次使用至少间隔 1 回合。

### 伤害结算（玩家 → 玩家）

```
普攻伤害 = 最终攻击                                # PVP 普攻不含灵力（PVE 才含）
技能伤害 = 基础伤害 × (1 + (等级-1)×15%)           # 蓝耗同样随等级 +15%/级
         × (1 + 玄冰灵根技能伤害加成 15%)
再乘    = × (1 + 离火灵根增伤 10%)                   # DAMAGE_BOOST 特效
暴击    = × (1.5 + 惊雷灵根暴击伤害加成 0.3)
最终    = 上述结果 + 随机(-5 ~ +5) - 对方最终防御/3
       × (1 - 厚土灵根减伤 15%)                      # 作用于防守方受到的总伤
保底    = 至少 1
暴击率  = min(60%, 最终速度/400) + 太乙金灵根暴击率加成 5%
```

> 暴击率的「速度折算部分」上限 60%（`速度/400`），太乙金灵根 +5% 的暴击率加成在封顶值之上再叠加；技能等级与灵根特效的加成规则与 PVE 完全一致（技能伤害 / 蓝耗随等级 +15%/级，玄冥水灵根减免蓝耗 20%）。

## 战斗策略

玩家可预先设置个人战斗策略，战斗时**仅影响 PVP**（PVE 自动战斗不读取策略），持久化保存。

| 策略 | 存储值 | 别名 | 效果（源码事实） |
|------|:---:|------|------|
| 猛攻 | `aggressive` | 进攻 / 猛 | 优先使用伤害最高的可用攻击技能，全力输出 |
| 均衡（默认） | `balanced` | 平衡 / 均 | 同样优先选择伤害最高的可用攻击技能，见招拆招 |
| 防守 | `defensive` | 防御 / 守 | **保留一半法力**（蓝量低于当前法力一半时不再放技能，转普攻），稳扎稳打 |

- 设置指令：`/战斗策略 <猛攻|均衡|防守>`（无参数时显示当前策略）。
- 均衡与猛攻在当前实现中的技能选择逻辑相同（都选伤害最高者）；两者的差异体现在**防守会保留一半法力**，从而改变可用技能池。
- 默认策略为均衡；未设置时的战斗日志中防守战术会标注「沉稳」。

## 胜负与奖励

- 胜利条件：击杀对方（对方生命归 0）；20 回合内未分出胜负按剩余生命判定，相同判平局。
- **奖励只发放给胜者**（无论胜者是发起方还是应战方）：

| 奖励 | 规则（源码事实） |
|------|------|
| 经验 | `50 + 败者等级 × 10`；若胜者境界**低于**败者则 **×2**；再 + 随机 0 ~ 29 |
| 金币 | 随机 50 ~ 199 |
| 熟练度 | 双方本场使用过的技能各 **+15** 熟练度 |
| 胜场 | 胜者 PVP 胜场计数 +1，并触发称号检查 |
| 每日机缘 | 双方各计入「今日机缘 · 战斗」进度 |

- 发起挑战本身无金币 / 灵石消耗，但消耗**每日 PVP 次数**（见下）。
- 平局无经验金币奖励；战报以「🤝 平局」收尾。
- 战斗结束（无论胜负平）都会触发 `COMBAT_ENDED` 插件事件，供插件监听。

## PVP 专属限制

| 限制 | 说明（源码事实） |
|------|------|
| 生命门槛 | 双方 HP 都必须 > 0，重伤（HP = 0）不可发起或应战 |
| 不能挑战自己 | 直接拒绝 |
| 每日次数 | **每人每天最多参与 10 次**（发起 + 接受合计），次数持久化到 `player_daily` 表（跨天自动清零、重启不丢失），用尽后提示「今日切磋次数已用完」 |
| 响应时限 | 30 秒未回应自动作废；过期挑战在发起新挑战时清理 |
| 同时在途 | 发起方同一时间只能有一个未决挑战；同一被挑战者被多人挑战时只保留最近一次 |
| 战斗损耗 | 战后双方**真实剩余 HP/MP 持久化**，损耗不会自动回满（需疗伤 / 服药恢复） |

## QQ 指令

| 指令 | 说明 | 权限 / 模块 |
|------|------|------|
| `/挑战 <角色名>` `/pvp` | 发起切磋挑战（现代入口，带私聊通知） | `game.pvp.challenge` · 模块 `pvp` |
| `/挑战 接受`（accept）/ `/挑战 拒绝`（reject） | 回应挑战 | 同上 |
| `/决斗 <角色名>`、`/切磋`、`/fight` | 传统切磋入口，同挑战流程 | 模块 `pvp`（无权限码） |
| `/战斗策略 <猛攻\|均衡\|防守>` `/战术` `/tactic` | 查看 / 设置战斗策略 | 模块 `skill`（技能） |
| `/战斗` `/讨伐` `/boss` | PVE / Boss 快捷入口（见 [PVE 战斗与 Boss](../player/pve-combat)） | 模块 `pvp` |

### 兼容入口说明（源码事实）

传统「决斗」入口（`onebot/command/pvp` 包）与「挑战」入口（`onebot/command/combat` 包）均已生效；原由两个指令同时占用别名 **`pvp`** 的冲突已修复：传统入口移除 `pvp` 别名（保留 `决斗`、`切磋`、`fight`、`战斗`、`讨伐`、`boss`），`/pvp` 现在唯一指向「挑战」实现（含被挑战者私聊通知与权限码门控，推荐入口）。

## 已知现状（源码事实）

- 战败方的生命值会真实扣减并持久化，需要疗伤或服药恢复后才能再次参战（旧版文档所述「战后自动恢复至战前数值」在当前版本已不成立）。
- 防守战术在战斗日志中以「沉稳」字样标注。
- 战术设置指令所属模块为 `skill`（技能模块），停用技能模块时 `/战斗策略` 不可用；但已保存的策略值仍会在 PVP 结算中生效。
