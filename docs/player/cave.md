# 洞府系统

洞府是玩家的私人修炼场所，提供**灵气收集**（兑换灵石）、**修炼加成**与**背包扩容**。通过 QQ 指令 `/洞府` 或 REST / WebSocket 接口操作。

## 开辟洞府

| 条件 | 值 |
|------|------|
| 境界要求 | realm ≥ 3（代码常量 `MIN_REALM_CREATE=3`，即**金丹期**；提示文案写「筑基期」，与实现不符） |
| 消耗 | **300 灵石** |
| 名称 | 默认「山间洞府」，最长 10 字 |
| 限制 | 一名玩家一座洞府 |

## 洞府等级

| 参数 | 公式 |
|------|------|
| 最高等级 | 10 |
| 灵气上限 | `1000 + (等级 - 1) × 500` |
| 修炼加成 | `等级 × 5%` |
| 背包存储加成 | `等级 × 10` 格 |
| 升级费用 | `当前等级 × 500` 灵石 |

## 灵气系统

- 洞府灵气每 **10 秒 +10**，封顶于上限
- **收集**：每 **5 分钟**可收集一次，将当前灵气 **1:1 兑换为灵石**；有阵法加成时 `灵气 × (100 + 阵法加成) / 100`
- 灵气为 0 时不可收集

## 洞府冥想

在洞府内冥想可固定获得经验：

```
冥想经验 = 100 + (洞府修炼加成 + 阵法修炼加成) × 10
```

冥想时的心魔判定使用 `caveLevel = 洞府等级 + 阵法心魔抗性 / 2`（洞府等级 × 3% 心魔抵抗）。

> 注意：洞府修炼加成**不作用于**普通打坐闭关（`/打坐`），仅冥想与灵石提纯等玩法使用。

## 灵石提纯（关联）

洞府灵气也是**灵石提纯**的必要消耗（`EconomyService.purifySpiritStone`）：

| 提纯 | 境界要求 | 消耗洞府灵气 | 基础成功率 | 消耗源灵石 |
|------|:---:|:---:|:---:|:---:|
| 下品 → 中品 | 筑基期（realm ≥ 2） | 100 | 90% | 1000 下品 |
| 中品 → 上品 | 元婴期（realm ≥ 4） | 1000 | 60% | 1000 中品 |
| 上品 → 极品 | 大乘期（realm ≥ 7） | 10000 | 30% | 1000 上品 |

成功率修正：`min(98%, 基础率 + min(15%, 灵力 / 2000))`；**失败也消耗灵石与灵气**。

| `/洞府 信息` | 查看等级 / 灵气 / 加成 |
| `/洞府 收集` | 收集灵气兑换灵石 |
| `/洞府 冥想` | 洞府冥想获得经验 |
| `/洞府 升级` | 升级洞府 |
