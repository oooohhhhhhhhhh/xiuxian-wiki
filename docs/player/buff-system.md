# Buff 系统

Buff 是丹药、符箓与装备赋予的**临时 / 永久增益**，作用在角色的攻击 / 防御 / 速度 / 神识（灵力）属性上，并另有独立的**经验倍率**与**伤害反弹**两类特殊增益。Buff 由 `BuffService` 统一管理：属性型 Buff 持久化于 `player_buffs` 表，到期自动回退属性；经验 / 反弹型 Buff 存于进程内存（重启失效）。查看入口为 `/增益`（`BuffCommand`，分类「实用功能」，模块 `buff`）。

## 机制说明

### 属性型 Buff（`player_buffs` 表）

- 每次使用 Buff 道具，效果类 `BuffEffect` 生成一条记录：`buff_id`（编码为 `buff_攻击_防御_速度_灵力`）、四维加成与 `expire_time`；
- **加成立即叠加到玩家属性**（攻击 / 防御 / 速度 / 神识各列），过期自动回退——因此对战斗、突破（神识加成）、心魔抵抗（神识）等一切按面板属性结算的系统均实时生效；
- **叠加规则**：相同 `buff_id`（同属性组合的同种丹药）重复使用**只刷新时长、不重复叠加属性**；不同 `buff_id` 之间的加成直接相加（跨 Buff 叠加）；
- **过期清理**：服务端每 **1 秒**扫描一次过期 Buff（`checkExpiredBuffs`），事务内回退属性并删除记录；每 30 秒顺带清理内存型过期增益；
- **重启恢复**：`player_buffs` 持久化未过期记录，玩家数据加载时 `reloadBuffsOnStartup` 自动把未过期 Buff 的属性重新加上；
- `/增益` 列出每条活跃 Buff 的四维加成与剩余秒数，并汇总显示总增益。

### 经验倍率与伤害反弹（内存型）

- **经验倍率**：`EXP_BOOSTS`（playerId → {加成百分比, 到期时间}）。`addExperience` 结算经验时若倍率 >1 则 `经验 × (1 + 加成/100)`，因此对**修炼结算、晨修、机缘奖励、战斗经验、秘籍参悟**等一切经验入口生效；同类型使用仅刷新时长；**重启即失效**，且不显示在 `/增益` 中。
- **伤害反弹**：`REFLECTION_BUFFS`（playerId → {反弹百分比, 到期时间}）。战斗结算时攻击方受到被命中方的反弹伤害（`CombatService.getReflectionPercent`，PVE 与 PVP 均接入）；同上为内存态。

## 可枚举的 Buff 物品（数值以代码为准）

### 时限属性 Buff（丹药 / 符箓，`BuffEffect`，字段序 = 攻击/防御/速度/灵力 + 时长）

| 物品（key） | 攻击 | 防御 | 速度 | 灵力 | 时长 |
|------|:---:|:---:|:---:|:---:|:---:|
| 神力丹（`mtxgdn:power_buff_pill`） | +30 | +20 | - | - | 60 秒 |
| 灵力丹（`mtxgdn:spirit_boost_pill`） | - | - | - | +50 | 300 秒 |
| 神行符（`mtxgdn:speed_talisman`） | - | - | +25 | +10 | 120 秒 |
| 终极神力丹（`mtxgdn:ultimate_power_pill`） | +50 | +50 | +20 | +30 | 600 秒 |

> **说明**：上表数值来自各物品类构造的 `BuffEffect.of(...)`；语言文件 `zh_cn.json` 中对应描述已与代码实现同步（灵力丹 300 秒、终极神力丹 分维 50-50-20-30 / 600 秒）。

### 特殊 Buff（内存型）

| 物品（key） | 效果 | 时长 | 生效点 |
|------|------|:---:|------|
| 经验加倍丹（`mtxgdn:exp_multiplier_pill`） | 经验获取 **+50%** | 300 秒 | `PlayerService.addExperience`（乘算，1.5 倍） |
| 反射丹（`mtxgdn:damage_reflection_pill`） | 反弹所受伤害的 **30%** | 120 秒 | `CombatService` 战斗结算（PVE/PVP） |

> 语言文件中的描述已与代码一致（经验加倍丹 +50% × 300 秒、反射丹 30% × 120 秒），物品实际效果见上表。

### 装备类永久加成（`BuffEffect` 时长 = 0）

装备穿戴时直接叠加、换装/卸下时按同数值回退（`ItemService.equipItem` / `unequipItem` 中的 `BuffEffect` 分支；本质是"装备即永久增益"，不产生倒计时记录）：

| 装备（key） | 攻击 | 防御 | 速度 | 灵力 |
|------|:---:|:---:|:---:|:---:|
| 灵剑（`mtxgdn:spirit_sword`） | +50 | - | +10 | +20 |
| 龙剑（`mtxgdn:dragon_sword`） | +200 | +50 | +50 | +80 |
| 护身玉（`mtxgdn:guardian_jade`） | - | +100 | - | +50 |
| 玉甲（`mtxgdn:jade_armor`） | +80 | +200 | +30 | +100 |
| 星辰法袍（`mtxgdn:star_robes`） | +40 | +150 | +40 | +120 |
| 凤凰铠甲（`mtxgdn:phoenix_armor`） | +60 | +300 | +20 | +60 |
| 麒麟护符（`mtxgdn:qilin_amulet`） | +150 | +200 | +100 | +200 |

## 在修炼与战斗中的生效范围

| 场景 | 生效内容 |
|------|------|
| 经验结算（修炼 / 晨修 / 机缘 / 战斗 / 秘籍等） | 经验加倍丹的 **+50%** 倍率（`addExperience` 统一入口） |
| 战斗属性 | 属性型 Buff 直接抬高攻击/防御/速度/神识（角色面板属性即战斗输入），到期/卸下自动回落 |
| 伤害反弹 | 反射丹按 30% 反弹（`CombatService` 结算） |
| 间接影响 | 神识 Buff 会抬高突破成功率灵力项与心魔抵抗等按神识计算的数值（属正常面板联动，非独立 Buff 通道） |
