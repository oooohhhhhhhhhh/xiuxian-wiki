# Buff 系统

使用物品可获得**临时属性加成**（攻击 / 防御 / 速度 / 灵力），到期自动过期并扣除对应属性；装备类物品则以「永久 Buff」形式生效（卸下时扣除）。

## 机制说明

- 每次使用 Buff 物品生成一条独立 Buff 记录（`player_buffs` 表）
- **同属性直接相加叠加**，无上限、无覆盖
- 服务端每秒检查过期 Buff，过期后自动扣除属性并删除记录
- 服务器重启时自动恢复未过期的 Buff
- 装备类物品（灵剑、护身玉等）的加成以永久 Buff 形式在穿戴时加入、卸下时扣除

## 可用的 Buff 物品

| 物品 | 加成（攻/防/速/灵） | 时长 |
|------|:---:|:---:|
| 神力丹 | +30 / +20 / - / - | 60 秒 |
| 反射丹 | - / +30 / - / - | 120 秒 |
| 神行符 | - / - / +25 / +10 | 120 秒 |
| 灵力丹 | - / - / - / +50 | 300 秒 |
| 终极神力丹 | +50 / +50 / +20 / +30 | 600 秒 |

> 说明（源码事实）：经验加倍丹的 Buff 各项数值为 0（无实际效果）；反射丹实为防御加成（非伤害反弹）。
