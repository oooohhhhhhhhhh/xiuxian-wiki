# 游历事件一览

本文列出 `/游历` 可触发的全部 **13 种随机事件**及其精确数值，事件定义类位于 `data/mtxgdn/explorationevent`（key 均带 `mtxgdn:` 命名空间，共 13 个 `extends ExplorationEvent` 的类），由 `ExplorationEventRegistry` 按权重抽签。抽奖语义与符号约定：

- 事件命中：先累加**总权重 152**，再掷 `[0, 152)` 骰子，按注册顺序命中事件；
- 奖励区间：随机整数 `[a, b)` **左闭右开**；
- 百分比分支：`random.nextDouble()` 掷 `[0, 1)` 骰子；
- 缩放基数：多数奖励形如 `n × N`，其中 **n = 境界编号 + 1**（境界编号 r：凡人 = 0 … 金仙 = 10，故凡人 n = 1、金仙 n = 11）；
- 经验 / 金币 / 灵石到账即结算，物品写入背包（itemKey 支持裸 key 自动补 `mtxgdn:` 前缀）。

## 遭遇妖兽（权重 25）

按**玩家当前境界** r 生成随机妖兽（`Monster.random`），进入完整回合制 PVE 战斗（上限 **30 回合**）。妖兽基础属性与奖励：

```
HP = 30 + r×35 + 随机(r×20 + 10)     攻 = 5 + r×12 + 随机(r×8 + 5)
防 = 2 + r×4  + 随机(r×3 + 2)        速 = 3 + r×2  + 随机(r×3 + 1)
经验 = r×80 + 随机(r×40 + 10)         金币 = 随机(r×20 + 10)    灵石 = 随机(r×10 + 5)
```

- 掉落表为 6 种普通物品（灵草 / 铁矿石 / 回血丹 / 回蓝丹 / 回灵丹 / 妖兽内丹）之一，基础掉落概率 **30%~45%**，并受季节掉落倍率修正（`掉落率 × 季节掉落倍率`）；
- 胜负与奖励由 PVE 战斗结算（技能、灵根特效、Buff 全部生效），详见 [PVE 战斗](../player/pve-combat)。

## 发现宝藏（权重 25）

```
金币 = 随机(n×50, n×300 + 100)     # n = 境界编号 + 1
灵石 = 随机(n×10, n×80 + 20)
```

凡人（r = 0）：金币 [50, 400)、灵石 [10, 100)；炼气（r = 1）：金币 [100, 700)、灵石 [20, 180)。

> 注意：游历中的宝藏**不享受**火土木灵根的灵石掉落加成（+20% 的 `SPIRIT_STONE_DROP` 只在秘境宝藏、晨修、战斗掉落等结算路径生效）。

## 灵泉沐浴（权重 8）

- 生命与法力各回复 `max/4 + 随机(max/4)`，即约 **25%~50%**（SQL 侧以 `LEAST(max_hp, hp + 恢复量)` 封顶，不会溢出）；
- 经验 `n×80`；另获灵泉水 1~3 个。

## 遭遇陷阱（权重 7）

- 损失 `最大生命/10 + 随机(最大生命/8)`，即约 **10%~22.5%** 最大生命，HP 最低保留 **1**；
- 无任何奖励。

## 一无所获（权重 5）

- 保底经验 `n×10`（漫步感悟）。

## 已知限制与细节（源码事实）

- **散修赠物正常发放**：`CultivatorEvent` 赠物分支改用带 `mtxgdn:` 前缀的完整注册 key，`ItemRegistry.contains` 校验可命中，20% 分支在 60% 概率下真实发放物品（其余落入金币兜底 `n×100`）；
- **材料稀有度标签与分桶一致**：`MaterialEvent` 第三列文字标签已按实际分桶区间修正（<0.5 普通档 / <0.85 稀有档 / 其余史诗档），命名同步为注册名；
- **物品名称与注册译名统一**：事件内嵌文案改用注册译名——「妖兽内丹」（原兽核）、「星沙」（原星辰沙）、「星草种子」（原星辰草种子），发放的 key 均为注册项，背包显示名与事件提示一致；
- **灵泉水数量可见**：`SpiritSpringEvent` 现在把数量写入结果对象（`setItemQuantity`），结算消息与 `/游历` 返回均显示「灵泉水 xN」；
- 事件名称/描述经 `LangManager` 从 `zh_cn.json` 取 `explorationevent.<key>.name/desc`，个别 key 缺翻译时退回 key 本身。
