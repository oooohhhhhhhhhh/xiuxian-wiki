# 游历事件一览

游历探索的 13 种随机事件及详细奖励规则（`data/mtxgdn/explorationevent`）。奖励公式中 `r` 表示境界编号（realm，凡人=0…金仙=10），随机区间为 `[a, b)` 语义。

## 遭遇妖兽（权重 25，16.4%）

生成随机妖兽并触发完整回合制 PVE 战斗（30 回合上限）。妖兽属性随玩家境界缩放：

```
攻 = 5 + r×12（+随机）；防 = 2 + r×4；速 = 3 + r×2；HP = 30 + r×35
经验 = r×80 + 随机；金币 = 随机(0, r×20+10)；灵石 = 随机(0, r×10+5)
```

## 发现宝藏（权重 25，16.4%）

```
金币 = 随机(r×50, r×300+100)     # 凡人: [50,400)，炼气: [100,700)
灵石 = 随机(r×10, r×80+20)
```

## 采集灵草（权重 15，9.9%）

获得灵草 / 回血丹 / 回蓝丹 / 灵泉水 **1~2 个**（随机数量）。

## 遇到修士（权重 13，8.6%）

| 分支 | 概率 | 奖励 |
|------|:---:|------|
| 交流心得 | 50% | 经验 `(r+1)×120` |
| 赠灵石 | 30% | 灵石 `(r+1)×30` |
| 赠物 / 金币 | 20% | 金币 `(r+1)×100` |

## 发现种子（权重 12，7.9%）

种子 1~2 颗，按稀有度分层：普通（50%）灵草 / 暗冰草 / 火焰藤 / 千年人参种子；稀有（35%）幽冥花 / 星辰草 / 血灵芝种子；传说（15%）天山雪莲种子。

## 采集材料（权重 10，6.6%）

材料 1~3 个，按稀有度分层：普通（50%）灵草 / 铁矿石 / 银矿石 / 金矿石 / 秘银矿石 / 兽核；稀有（35%）魔核 / 龙血晶 / 冰晶 / 天火石 / 星辰沙；史诗（15%）灵珠 / 千年何首乌 / 深海珊瑚 / 鬼火精华 / 天蚕丝 / 血玉髓。

## 偶遇游商（权重 10，6.6%）

| 分支 | 概率 | 奖励 |
|------|:---:|------|
| 购强化石 | 30% | 强化石 1~3 颗 |
| 赠送物品 | 30% | 回血丹 / 回蓝丹 / 灵泉水 / 兽核 1~2 个 |
| 指路报酬 | 25% | 金币 `(r+1)×200 + 随机(500)` |
| 情报交换 | 15% | 灵石 `(r+1)×40` |

## 发现遗迹（权重 10，6.6%）

| 分支 | 概率 | 奖励 |
|------|:---:|------|
| 封印宝物 | 40% | 修炼丹 / 功法残页 / 灵剑 / 护身玉 / 基础剑诀 / 火龙术 / 玉甲 / 神力丹 / 神行符 / 天雷符 / 龙血晶 / 灵石袋 中 1 个 |
| 大量灵石 | 35% | 灵石 `(r+1)×150` |
| 功法残篇 | 25% | 经验 `(r+1)×200` |

## 神秘奇遇（权重 8，5.3%）

| 分支 | 概率 | 奖励 |
|------|:---:|------|
| 传说材料 | 20% | 五色神石 / 凤凰胆 / 麒麟角 / 龙鳞 / 凤凰羽毛 / 龙骨 中 1 个 |
| 捡到钱袋 | 20% | 金币 500~2000 |
| 修炼秘籍 | 20% | 经验 `(r+1)×200` |
| 珍稀种子 | 15% | 种子 2~3 颗 |
| 溪边灵石 | 15% | 灵石 50~200 |
| 误入秘境 | 10% | 经验 `(r+1)×500` |

## 灵泉沐浴（权重 8，5.3%）

- 回复 **25%~50%** 最大生命与法力
- 经验 `(r+1)×80`，另得灵泉水 1~3 个

## 遭遇陷阱（权重 7，4.6%）

- 损失约 **10%~22.5%** 最大生命（`maxHp/10 + 随机(maxHp/8)`），HP 最低为 1

## 一无所获（权重 5，3.3%）

- 保底经验 `(r+1)×10`

## 奇遇古塔（权重 4，2.6%）

| 分支 | 概率 | 奖励 |
|------|:---:|------|
| 塔顶至宝 | 30% | 天玉 或 渡劫丹 ×1 |
| 参悟符文 | 30% | 经验 `(r+1)×300` |
| 地宫矿物 | 20% | 强化石 3~7 颗 |
| 前人财宝 | 20% | 灵石 `(r+1)×200` + 金币 `(r+1)×500` |

## 已知限制（源码事实）

- 「遇到修士」的赠物分支与普通妖兽的物品掉落表使用裸 key，实际**不会发放物品**（自动回退为金币）
- 部分事件名称缺少 i18n 翻译（mystery / seed / merchant / spirit_spring / strange_tower / material）
