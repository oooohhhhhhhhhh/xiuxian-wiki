# 秘境探索

秘境是固定的探索区域，有**境界门槛**与**冷却时间**，进入后随机遭遇事件；部分高等级秘境支持**团队副本**（多人组队挑战关卡 + 三形态 Boss）。

## 进入规则

- 境界 ≥ 秘境需求；HP > 0（重伤禁止）
- 冷却按**每个秘境独立**计算；成功后计入「今日机缘·秘境 1 次」
- 名称解析支持：完整 key、序号、精确中文名、模糊包含

## 事件概率

进入秘境后随机遭遇（各秘境共用同一套概率）：

| 事件 | 概率 |
|------|:---:|
| 发现宝藏 | 20% |
| 遭遇妖兽（普通怪） | 20% |
| **遭遇守护者 Boss** | **10%** |
| 采集灵草 | 15% |
| 遇到散修 | 13% |
| 发现遗迹 | 10% |
| 机关陷阱 | 7% |
| 一无所获 | 5% |

奖励与游历同类事件一致；宝藏灵石受**火土木灵根**（+20%）加成。

## 守护者 Boss

单人遭遇 Boss 时按**需求境界**生成守护者（名称按 `需求境界-1` 取档，同一档位共享名称）：

| 需求境界 | Boss 名称 |
|:---:|------|
| 凡人 / 炼气 | 草原霸主·奔雷兽 |
| 筑基 | 暗影领主·噬魂蛛皇 |
| 金丹 | 兽王·金翼裂天雕 |
| 元婴 | 遗迹守卫·青铜巨像 |
| 化神 | 战场英魂·不灭战将 |
| 更高 | 远古魔神·混沌之影 |

Boss 属性约为基础妖兽的 3 倍以上，掉落率更高（60%~85%）。

## 团队副本（Raid）

雷霆峡谷、九天平台、仙人洞府支持组队挑战：

| 规则 | 值 |
|------|------|
| 队伍 | 2~5 人，队长发起，全体通过境界与冷却检查 |
| 小怪波数 | `max(2, 需求境界)` 波（金丹 3 波 / 元婴 4 波 / 化神 5 波），每波 1~2 只 |
| 最终 Boss | **三形态**（血量 66% / 33% 变身），属性逐档提升（最高 2.0 倍），玩家被削弱 5% / 10% / 15% |
| 回合上限 | 50 回合，Boss 随机攻击，任一成员倒下即团灭失败 |
| 通关奖励 | 基础经验 `(需求境界+1)×500`、金币 ×300、灵石 ×100，团队加成 `1 + 0.2×(人数-1)`，平分给存活成员 |
| Boss 掉落 | 按最终形态掉落率（50% / 65% / 80%）对每位存活成员掷骰 |
| 称号 | 尾刀玩家获得「副本征服者」称号 |

> 注意：需求境界 ≥ 4 的副本 Boss 奖励表引用的物品未注册，实际**不掉落物品**（源码事实）。
