# 秘境探索

秘境是固定的探索区域：每一处都有**境界门槛**、**进入冷却**与**专属遭遇概率**，部分高阶秘境支持**团队副本**（组队清小怪 + 三形态 Boss）。秘境定义类位于 `data/mtxgdn/secretrealm`（共 **10 个** `extends SecretRealm` 的类，启动时经 `SecretRealmScanner` 注册），逻辑集中在 `game/service/SecretRealmService.java`。

## 指令

| 指令（中文 / 英文别名） | 参数 | 说明 |
|------|------|------|
| `/秘境` `/secret` | 无 | 列出**当前可进入**的秘境（按境界门槛过滤：所需境界 ≤ 玩家境界），含所需境界、冷却秒数与描述 |
| `/进入秘境 <名称或序号>` `/secret_enter` | 秘境名称 / 序号 | 单人进入指定秘境并随机遭遇事件 |
| `/组队 副本 <秘境名>` | 秘境名称 | 队长发起**团队副本**（需先组队，组队与副本规则见 [组队 PVE](../player/pve-combat)） |

- **权限码**：`game.secret_realm`；**分类**：探索。
- **模块门控**：`/秘境`、`/进入秘境` 挂载于内置模块 `secret_realm`；组队副本由团队模块（`team`）提供入口。
- 名称解析顺序（`SecretRealmRegistry.resolve`）：完整 key（如 `mtxgdn:thunder_valley`）→ **数字序号**（按需求境界升序排列，1 起）→ 精确中文名 → 中文名 / key 的**模糊包含**匹配。
- 团队副本另有 REST / WebSocket 接口（`POST /game/...` 侧 `SecretRealmService.enterRaid`），由 `/组队 副本` 与客户端 SDK 调用。

## 进入规则（单人）

- 前提：已创建角色、境界 ≥ 目标秘境需求、HP > 0（重伤禁止）；
- **冷却判定使用单一时间戳**：玩家表 `last_secret_realm_time` 记录上次进入任意秘境的时间，进入时要求「距上次 ≥ 目标秘境冷却时长」——即连续进入不同秘境也会被上一次的时间戳约束（以目标秘境的冷却时长为准）；判定与时间戳更新在同一事务内完成（防并发刷取）；
- 成功后每次进入都计入「今日机缘·秘境 1 次」进度（`DailyService.onSecretRealm`），并累计秘境次数（`players.secret_realm_count`），用于「秘境探险家」称号等计数；
- 冷却中的提示为「你刚探索过【X】秘境，还需要等待一段时间」。

## 秘境遭遇概率

进入后按一次掷骰触发 **8 类遭遇之一**。奖励数值普遍以玩家境界缩放（`n = 玩家境界编号 + 1`，公式与游历事件一致，见 [游历事件一览](../player/exploration-events)）。

### 普通秘境（需求境界 < 合体，即表中前 8 处）

| 遭遇 | 概率 |
|------|:---:|
| 发现宝藏 | 20% |
| 遭遇妖兽 | 20% |
| **遭遇守护者（Boss）** | **10%** |
| 采集灵草 | 15% |
| 遇到散修 | 13% |
| 发现遗迹 | 10% |
| 机关陷阱 | 7% |
| 一无所获 | 5% |

### 高境界秘境（合体 / 大乘：混元仙府、太虚天宫）

Boss 遭遇概率**翻倍**，另有 15% 概率触发区域专属奇遇：

| 遭遇 | 概率 |
|------|:---:|
| **区域专属奇遇** | **15%** |
| 发现宝藏 | 20% |
| 遭遇妖兽 | 10% |
| **遭遇守护者（Boss）** | **20%** |
| 采集灵草 | 10% |
| 遇到散修 | 10% |
| 发现遗迹 | 7% |
| 机关陷阱 | 5% |
| 一无所获 | 3% |

区域专属奇遇按秘境区分：

- **混元仙府·混沌灵泉**：经验 `(需求境界+1)×2000 + 随机(2000, 8000)`、灵石 `(需求境界+1)×150 + 随机(100, 500)`；
- **太虚天宫·天宫宝库**：随机获得 1 件传说材料（五色神石 / 龙心 / 麒麟血 / 凤凰胆 / 万年灵芝 / 天元丹 / 乾坤造化丹）。

其余通用差异（源码事实）：

- **秘境妖兽按区域境界生成**（`Monster.random(需求境界)`），而不是按玩家境界——高境界玩家去低阶秘境也不会遇到碾压级妖兽；
- 宝藏的灵石享受**火土木灵根** `SPIRIT_STONE_DROP` 加成（+20%，乘算后发放）；
- 高境界秘境的**守护者被击败后额外掉落 1 件传说材料**（同天宫宝库材料池）。

## 守护者 Boss（单人遭遇）

单人遭遇守护者时，按**区域需求境界** `req` 生成（`Monster.createBossForRealm(req)`，内部档位 = `req - 1`）：

| 区域需求境界 | Boss 名称 |
|:---:|------|
| 凡人 / 炼气 | 草原霸主·奔雷兽 |
| 筑基 | 暗影领主·噬魂蛛皇 |
| 金丹 | 兽王·金翼裂天雕 |
| 元婴 | 遗迹守卫·青铜巨像 |
| 化神 | 战场英魂·不灭战将 |
| 合体 | 洞府守护灵·九霄剑魂 |
| 大乘 | 混沌真君·太虚老祖 |

Boss 属性约为普通妖兽的数倍且**随档位成长**（Boss 档位 `r = max(1, req-1)`：HP ≈ `80 + r×120`、攻 ≈ `15 + r×30`、防 ≈ `8 + r×12`、速 ≈ `5 + r×5`，另有随机浮动）；掉落概率 60%~85%，可掉强化石、修炼丹、功法残页、护身玉、神行符、天玉等。

## 团队副本（Raid）

以下 5 处秘境标记为团队副本：**雷霆峡谷 / 九天平台 / 仙人洞府 / 混元仙府 / 太虚天宫**。

### 发起与准入

- 队伍 **2~5 人**（`TeamService`：`MIN_TEAM_SIZE = 2`、`MAX_TEAM_SIZE = 5`），仅**队长**可发起（`/组队 副本 <秘境名>`）；
- 全体成员须通过：境界 ≥ 需求境界、HP > 0、冷却检查（各自距上次秘境 ≥ 目标秘境冷却）；通过后队长与成员的时间戳一并刷新。

### 关卡流程

1. **小怪波数** = `max(2, 需求境界)`：雷霆峡谷 3 波、九天平台 4 波、仙人洞府 5 波、混元仙府 6 波、太虚天宫 7 波；每波 1~2 只（按区域境界生成），由存活成员**逐个上前迎战**，任一成员击杀即过该怪，全灭才判波失败；
2. 全部小怪清除后进入 **Boss 战**：Boss 分 **3 个形态**（命名随境界变化），血量为各形态 `HP 倍率 × 500 × 形态序` 之和（形态一 500 + 形态二 1400 + 形态三 3000 = **4900**），基础攻 500 / 防 300 / 速 100 乘各形态倍率；
3. Boss 血量降至 **66% / 33%** 时变身（形态二 / 形态三），属性提升、玩家输出被削弱 **5% / 10% / 15%**（各形态对应，三形态 HP/攻/防/速倍率 1.0/1.4/2.0 等递增）；
4. 每回合 Boss **随机攻击一名存活成员**，回合上限 **50**；全部成员阵亡即失败。

### 通关奖励

- **固定奖励**：基础经验 `(需求境界+1)×500`、金币 `×300`、灵石 `×100`，再乘团队加成 `1 + 0.2 × (人数 - 1)`，**平分给通关时存活成员**（逐人入账）；
- **Boss 掉落**：每位存活成员按最终形态掉落率（形态一二三对应 **50% / 65% / 80%**）独立掷骰，从该境界档的奖励表中随机 1 件（低阶为灵草 / 回血丹等，高阶含龙血晶、强化石、火龙术、玉甲，最高档含五色神石、天火石、龙骨、天元丹、天蚕丝等）；
- 尾刀（对 Boss 造成最后一击）的成员获得**「副本征服者」**称号（`raid_conqueror`，稀有度：稀有）；
- 失败无通关奖励，挑战结束后成员的 HP 按战斗结果回落（最低 0）。
