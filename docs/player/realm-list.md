# 境界一览

境界是角色的修为等级体系：每突破一个小境界需同时满足**修为（经验）**与**灵石**要求，成功后扣除对应消耗并一次性获得该境界的六维属性加成（生命 / 法力 / 攻击 / 防御 / 速度 / 神识）。全部数据由配置文件驱动：打包于 `src/main/resources/game/realm_config.json`，运行目录 `config/game/realm_config.json` 存在时优先加载外部文件（`GameConfigLoader`）。

## 配置结构

`realm_config.json` 由 `realms`（境界条目数组）与 `cultivationPerSecond`（修炼基础倍率）两部分组成，共 **11 大境界、29 个阶段条目**：

| 字段 | 含义 |
|------|------|
| `id` | 大境界序号（0~10：凡人→金仙） |
| `subRealm` | 小境界（0=初期 / 1=中期 / 2=后期） |
| `name` | 境界显示名（初期条目不带后缀，如「炼气期」「真仙」；中/后期带「·中期」「·后期」） |
| `description` | 境界描述 |
| `requiredExp` | 突破进入该境界所需的经验（凡人/金仙等已满级条目为 0） |
| `requiredSpiritStones` | 突破进入该境界所需消耗的灵石 |
| `hpBonus`/`mpBonus`/`attackBonus`/`defenseBonus`/`speedBonus`/`spiritBonus` | 突破成功时**一次性增加**到角色对应属性上的数值（随突破逐级累加） |
| `unlockSkillId` | 该境界关联解锁技能 ID（当前版本仅随突破结果返回，不自动习得） |

> 「神识」即玩家面板灵力属性（数据库 `spirit` 列）；各属性表头沿用面板名「生命 / 法力 / 攻击 / 防御 / 速度 / 神识」。

## 修炼基础倍率

`cultivationPerSecond`：`baseValue = 1`，`realmMultiplier` 按**大境界 id** 取倍率：

| 大境界 id | 凡人 | 炼气 | 筑基 | 金丹 | 元婴 | 化神 | 合体 | 大乘 | 渡劫 | 真仙 | 金仙 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 ~ 10 | 1.0 | 1.5 | 2.5 | 4.0 | 6.0 | 10.0 | 18.0 | 32.0 | 55.0 | 90.0 | 150.0 |

每秒修炼基础经验 = `baseValue × realmMultiplier`（实际按 double 累乘，最后一次性取整）。季节、地点灵气、灵根、天象、功法、称号、阵法会在此基础上叠加倍率，详见 [修炼系统](./cultivation)。

## 境界解锁技能字段

配置中每境界带 `unlockSkillId`（指向 [技能系统](./skills) 的技能 ID）：**筑基期初期=1、金丹期初期=2、元婴期初期=3、化神期初期=4、合体期初期=10、大乘期初期=11、渡劫期初期=12、真仙初期=13**，其余阶段为 0。

> 说明（源码现状）：该字段在 `RealmService.tryBreakthrough` 中被放入突破结果（`RealmBreakthroughResult.unlockedSkillId`）返回，**服务端不会据此自动习得技能**；技能仍通过 `/学习` 手动学习，门槛由技能自身的 `required_realm`（境界 ID）决定。
