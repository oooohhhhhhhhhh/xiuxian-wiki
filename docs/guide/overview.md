# 项目简介

**修仙世界**是一款基于 **Java 23** 开发的多人在线修仙主题文字 MUD 游戏服务端（当前版本 **V1.4.1-beta2**）。玩家创建角色后，可以通过修炼突破、渡劫飞升、游历探索、秘境征战、PVP 对战、坊市交易、宗门经营等方式在修仙世界中成长。

服务端提供 **REST API**、**WebSocket 实时通信**、**QQ 机器人（OneBot 服务端模式 / QQ 官方机器人）**、**Minecraft 接入**等多种接入方式，并内置完整的**插件系统**与可独立启停的**内置玩法模块**，开发者无需修改主程序即可扩展游戏内容。

## 技术栈

| 组件 | 技术 |
|------|------|
| 语言 | Java 23 |
| 构建工具 | Maven（shade 打包为可执行 fat-jar，主类 `com.mtxgdn.Main`） |

| 数据库 | SQLite（默认，零依赖） / MySQL（mysql-connector-j 9.7.0），sqlite-jdbc 3.49.1.0，HikariCP 5.0.1 连接池 |

| 邮件 | Jakarta Mail（Angus Mail 2.0.3，用于注册邮箱验证码） |
| 测试 | JUnit 5 + Mockito |

## 核心特性

### 角色与修炼

- **灵根系统**：共 **17 种灵根**、**8 档品级**（鸿蒙灵根 / 正灵根 / 天灵根 / 异灵根 / 双灵根 / 三灵根 / 四灵根 / 杂灵根），创建角色时按权重随机抽取（「正·五行灵根」不参与初始抽取，可通过灵根重铸等途径获得）；每种灵根拥有独特的属性加成与特效（暴击、回血、减伤、游历冷却、手续费减免、熟练度等）。金丹期以上可用 `/灵根 重铸`，消耗 **乾坤造化丹 ×1 + 灵石**重新随机抽取
- **境界系统**：由 `realm_config.json` 驱动，共 **11 大境界**（凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 真仙 → 金仙）、**29 个阶段条目**；凡人 / 金仙为单阶段，其余每境细分初期 / 中期 / 后期
- **突破与天劫**：大境界内的小境界突破直接成功；跨大境界突破需渡对应天劫，共 **7 类**（雷劫 / 心魔劫 / 风火劫 / 水劫 / 五行劫 / 阴阳劫 / 轮回劫），按目标境界分配。渡劫成功率由基础成功率叠加灵力、灵根、天劫对应属性加成，服用**渡劫丹**再 +10%，上限 95%；失败损失大量经验并身受重伤
- **修炼与挂机**：打坐修炼获得修为；离线收益按 **50% 效率**结算且上限 **8 小时**；闭关与离线修炼有概率触发**心魔**导致修为倒退
- **功法系统**：内置 **15 门默认功法**（修炼 / 攻击 / 防御 / 辅助等类型），玩家最多同时装备 **3 门**，装备后提供属性加成与修炼、战斗增益，可消耗金币与灵石升级
- **技能系统**：启动时写入默认技能库，战斗中按技能与战斗策略释放，使用获得熟练度（详见 [技能系统](../player/skills)）
- **洞府系统**：个人洞府灵力收集与升级（详见 [洞府系统](../player/cave)）

### 战斗

- **PVE 战斗**：游历与秘境中随机遭遇妖兽，完整回合制结算（技能、暴击、治疗、减伤、灵根特效、Buff 全部生效）；秘境含专属 Boss 战（Boss 支持多形态变身）
- **PVP 对战**：玩家间切磋 / 挑战，支持设置战斗策略（**猛攻 / 均衡 / 防守**）
- **组队与副本**：团队系统支持创建团队、组队进入副本型秘境
- **阵法系统**：布置阵法获得加成效果（详见 [阵法系统](../player/formation)）
- **Buff 系统**：丹药、道具与效果组件赋予的增益 / 减益，跨修炼与战斗结算生效

### 探索

- **游历探索**：内置 **13 种随机事件**按权重抽取，涵盖妖兽、宝藏、陷阱、灵草灵泉、奇遇、商人、修士等遭遇（详见 [游历事件一览](../player/exploration-events)）
- **秘境探索**：内置 **10 处秘境区域**，按境界设门槛并有进入冷却；内含随机遭遇与专属 Boss，支持组队进入
- **世界地图**：内置 **15 个地点**，地点间移动有耗时，不同地点提供不同的修炼灵气加成，含安全区设定
- **季节系统**：全服共享的「天道时序」，支持 `calendar`（按真实月份）与 `cycle`（按小时循环）两种更替模式，更替时全服广播，影响修炼、晨修、掉落与农场
- **每日天象**：全服每日随机 **6 种天象**之一（紫气东来 / 星辰耀天 / 血月当空 / 灵潮涌动 / 枯荣交替 / 万籁俱寂），按各自倍率影响修炼、游历、战斗与灵石产出

### 养成与经济

- **制造系统**：配方驱动的炼丹 / 炼器（丹药、装备、消耗品、种子等），成功率由配方决定，失败返还安慰经验
- **装备与强化**：装备可强化至 **+15**，成功 +1 级；失败可能**降级**甚至**碎裂**（携带护身符可保装免碎）
- **农场系统**：初始 **4 块**农田、上限 **12 块**，可种植 **16 种**灵植作物（灵草、千年人参、天山雪莲、蟠桃等，见 `CropConfig`）；支持浇水、施肥、病虫害防治（杀虫剂）与一键收获，产量受季节与灵根五行加成影响
- **称号系统**：内置 **19 个称号**、**5 档稀有度**（普通 / 稀有 / 珍贵 / 史诗 / 传说），提供属性加成与收集 / 装备
- **经济系统**：金币与灵石（多品阶灵石可提纯 / 兑换）双货币；签到、坊市挂单（**5%** 手续费，土金灵根减半）、拍卖行（7% 手续费）、灵庄存款、物品回收与商店、灵石加速修炼
- **能量系统**：物品 ↔ 能量等价互转的闭环，支持插件注册自定义物品能量值
- **兑换码**：管理员发放，玩家输入兑换奖励

### 社交与每日

- **宗门系统**：创建 / 申请 / 审批 / 任命 / 捐献 / 仓库 / 升级 / 宗主转让 / **宗门战**（宣战消耗声望并有冷却）；**5 级职位**体系（宗主 / 副宗主 / 长老 / 内门弟子 / 外门弟子）
- **好友与聊天**：好友申请双向确认；世界频道 + 私聊，消息持久化并经 WebSocket 实时推送
- **排行榜**：内置排行模块提供玩家排名查询；宗门另有声望排行
- **每日系统**：每日天象、晨修·紫气东来（5:00–11:00，连续天数加成）、今日机缘（嵌入游历 / 战斗 / 秘境 / 技能学习的每日目标）、灵根共鸣（累计活跃 **7 / 30 天**发放里程碑奖励）
- **新手引导**：内置新手引导任务链，逐步解锁各系统

### 平台能力

- **内置玩法模块化**：24 个玩法模块 + 4 个消息通道模块以「内置插件」形式运行，可在 `application.yml` 的 `built_in_plugins` 段或 Web 管理台运行时启停
- **插件系统**：第三方 jar 可注册命令 / 物品 / 游历事件 / 秘境 / 权限码 / REST 端点 / Web 管理页 / WebSocket 处理器；支持 `plugins.hot_swap` 文件热重载（详见 [插件开发](../dev/plugin-development)）
- **指令即路由**：一套中文指令（`/修炼`、`/突破` 等，附英文别名）同时注册为 QQ 指令与 REST 路由，物品支持中文名与 key 混用
- **玩家数据文件化**：一用户一 JSON（`data/players/`），变更自动落盘，后台可导出 / 还原
- **权限与 OAuth2**：RBAC 角色权限码体系 + 独立 OAuth2 令牌端点
- **国际化**：JSON 语言文件（当前 `zh_cn`），物品 / 秘境 / 事件等可整体翻译
- **低内存友好**：可关闭的缓存项与 `start-low-memory.bat` / `XIUXIAN_MEM` 等内存控制手段

## 接入方式

| 方式 | 地址（默认值） | 说明 |
|------|----------------|------|
| REST API | `http://127.0.0.1:8080/api/` | 监听地址与端口由 `server.host` / `server.port` 配置 |
| WebSocket | `ws://127.0.0.1:8080` | 与 REST 同一 Grizzly 服务，游戏实时网关（根路径） |
| Web 管理控制台 | `http://127.0.0.1:8080/admin/` | 登录需管理员账号 |
| 安装向导 | `http://127.0.0.1:8080/install` | 仅首次启动（未完成安装）时挂载 |
| OneBot QQ（服务端模式） | `ws://0.0.0.0:6700/onebot` | 默认实例见 `config/adapters.json`；本服务为 WebSocket **服务端**，Lagrange / LLOneBot 等 OneBot 实现以客户端方式接入 |
| QQ 官方机器人 | 出站连接官方网关，或本地 Webhook | 实例在 `config/adapters.json` 中配置（详见下方说明） |
| Minecraft MOTD | `127.0.0.1:25565` | 端口由 `motd.port` 配置 |
| 客户端 SDK | `com.mtxgdn.client` | `ApiClient` / `AuthApi` / `GameApi` / `GameWebSocketClient` |

### 消息通道（适配器）说明

适配器实例统一由 `config/adapters.json` 管理，首次启动自动生成默认配置（`onebot-default` 启用、`minecraft-default` 停用），并可在管理台运行时启停：

- **OneBot QQ**：WebSocket **服务端**模式（默认 `0.0.0.0:6700`，路径 `/onebot`），支持群聊 / 私聊指令、注册绑定、黑名单自动禁言等；另提供可选的**截图模拟模式**（通过窗口截图 + 键鼠模拟操作 QQ 客户端）
- **QQ 官方机器人**：基于 QQ 开放平台 API v2（AppID + ClientSecret 鉴权），接收方式二选一：
  - **WebSocket 网关**：出站连接官方网关 `wss://api.sgroup.qq.com/websocket`（支持沙箱网关），实现 Identify / 心跳 / 恢复协议
  - **Webhook**：本地回调监听（`QqWebhookServer`），端口必须为 **80 / 443 / 8080 / 8443** 之一，路径默认 `/qq/webhook`，带签名与时间戳校验
- **Minecraft**：MOTD 预览服务；可选内置 Minecraft 服务端适配（进程管理）与玩家直连通道；另提供 Bukkit 桥接插件 `XiuxianBridgePlugin`（`/xiuxian` 指令前缀，经 `build-mc-plugin.bat` 单独编译）

## 代码结构（速览）

```
src/main/java/
├── com/mtxgdn/                # 服务端主程序
│   ├── Main.java              # 入口：扫描注册、生命周期装配
│   ├── server/                # HTTP 服务装配（Grizzly / 停机钩子）
│   ├── rest/                  # REST 层（Auth / Game / Admin / OAuth / Install + 过滤器）
│   ├── websocket/             # WebSocket 游戏网关
│   ├── game/                  # 玩法核心：service（各玩法服务）、item / explorationevent /
│   │                          #   secretrealm（框架）、config / title / entity
│   ├── common/                # 统一响应 / 错误码 / 指令路由框架（classpath 扫描注册）
│   ├── onebot/                # OneBot WebSocket 服务端 + 分模块指令体系
│   ├── qq/                    # QQ 官方机器人通道（Webhook / 按钮）
│   ├── minecraft/             # MOTD + 内嵌服务器适配 + Bukkit 桥接插件
│   ├── adapter/               # 消息通道适配器框架（config/adapters.json 驱动）
│   ├── plugin/                # 插件系统（生命周期 / 事件总线 / Web UI / 内置模块）
│   └── util/ db/ entity/ service/ permission/ playerdata/ client/ demo/   # 支撑层
└── data/mtxgdn/               # 游戏数据定义（启动时自动扫描注册）
    ├── item/                  # 115 个物品定义类
    ├── secretrealm/           # 10 处秘境
    ├── explorationevent/      # 13 种游历事件
    └── lang/zh_cn.json        # 简体中文翻译
```

更详细的架构说明见 [架构总览](../dev/architecture)。
