# 项目简介

**修仙世界**是一款基于 **Java 23** 开发的多人在线修仙主题文字 MUD 游戏服务端。玩家创建角色后，可以通过修炼、突破境界、探索秘境、游历世界、PVP 对战、坊市交易、宗门争霸等方式在修仙世界中成长。

服务端提供 **REST API**、**WebSocket 实时通信**、**QQ 机器人（OneBot）**、**Minecraft 服务器接入**等多种接入方式，并内置完整的**插件系统**，开发者无需修改主程序即可扩展游戏内容。

## 技术栈

| 组件 | 技术 |
|------|------|
| 语言 | Java 23 |
| 构建工具 | Maven（shade 打包为可执行 fat-jar） |
| HTTP 框架 | Jersey 4.0.2 + Grizzly 4.0.2 |
| WebSocket | Grizzly WebSocket |
| 数据库 | MySQL 9.7 / SQLite 3.49 + HikariCP 连接池（一行配置切换） |
| 认证 | JWT 双令牌（jjwt 0.11.5）+ BCrypt 密码加密 |
| JSON | Gson 2.14.0 |
| 配置 | SnakeYAML 2.4 |
| 邮件 | Jakarta Mail（Angus Mail 2.0.3） |

## 核心特性

### 角色与修炼

- **灵根系统**：17 种灵根、8 个品级（鸿蒙 / 正 / 天 / 异 / 双 / 三 / 四 / 杂），创建角色时按权重随机抽取，每种灵根拥有独特的属性加成和特殊效果；金丹期后可用乾坤造化丹 + 灵石**重铸灵根**
- **境界系统**：11 大境界（凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 真仙 → 金仙），每境含初期 / 中期 / 后期三个小境界，配置由 `realm_config.json` 驱动
- **突破与天劫**：小境界 100% 成功；大境界突破触发天劫（雷劫 / 心魔劫 / 风火劫 / 水劫 / 五行劫 / 阴阳劫 / 轮回劫），成功率随境界递减，受灵根、灵力、渡劫丹影响
- **挂机修炼**：离线（50% 效率，上限 8 小时）与在线闭关，可能触发**心魔**（修为倒退）
- **功法系统**：11 种内功心法，最多同时运转 3 门，装备即获被动属性加成
- **技能系统**：攻击与辅助技能，使用获得熟练度，技能书可直升

### 战斗

- **PVE 战斗**：游历与秘境随机遭遇妖兽，完整回合制战斗，灵根特效全生效；秘境含专属 Boss 战
- **PVP 对战**：玩家间回合制切磋，支持技能、暴击、战斗策略（猛攻 / 均衡 / 防守）
- **阵法系统**：聚灵阵、护山阵、净化阵等阵法提供全局加成
- **组队系统**：与好友组队共同探索

### 探索

- **游历探索**：13 种随机事件，权重抽奖机制
- **秘境探索**：8 个秘境区域，境界门槛 + 冷却机制，随机遭遇宝藏 / 妖兽 / Boss / 灵草 / 陷阱等事件
- **世界地图**：15+ 地点，含路程耗时与地点灵气加成
- **洞府系统**：个人洞府，灵气影响提纯灵石等玩法
- **季节系统**：全服共享的「天道时序」，影响修炼、晨修、灵石、掉落、种田

### 养成与经济

- **制造系统**：炼丹 / 炼器 / 种植配方，成功率 + 失败安慰经验
- **装备强化**：强化至 +15，成功率逐级递减，高等级可能降级或碎装
- **农场系统**：4-12 块农田，种植 16+ 种作物，浇水施肥、病虫害防治、季节加成
- **称号系统**：18 个预设称号，属性加成 + 收集
- **经济系统**：金币 / 灵石多级货币、签到、坊市交易、拍卖行、灵庄存款、物品回收、灵石提纯
- **能量转化**：物品 ↔ 能量等价交换闭环，支持插件注册自定义能量值
- **兑换码**：管理员发放，玩家兑换奖励

### 社交

- **宗门系统**：创建 / 申请 / 审批 / 任命 / 捐献 / 仓库 / 升级 / 宗主转让 / 宗门战，5 级职位体系
- **好友与聊天**：好友申请双向确认，世界频道 + 私聊，消息持久化
- **排行榜**：境界榜 / 战力榜 / 财富榜 / 宗门声望榜
- **答题系统**：QQ 群内置题库答题玩法

### 每日与引导

- **每日系统**：天象（6 种全服随机）、晨修·紫气东来、今日机缘（嵌入游戏行为的每日目标）、灵根共鸣（7 / 30 天活跃奖励）
- **新手引导**：主线 + 自由探索双轨引导，逐步解锁各系统

## 接入方式

| 方式 | 地址 |
|------|------|
| REST API | `http://127.0.0.1:8080/api/` |
| WebSocket | `ws://127.0.0.1:8080` |
| Web 管理控制台 | `http://127.0.0.1:8080/admin/` |
| QQ 机器人（OneBot） | `ws://127.0.0.1:6700/onebot`（服务端模式） |
| Minecraft MOTD | `127.0.0.1:25565` |
| 客户端 SDK | `com.mtxgdn.client`（ApiClient / GameWebSocketClient） |

## 扩展能力

- **插件系统**：完整生命周期（onLoad / onEnable / onDisable），独立类加载器隔离，可注册命令 / 物品 / 游历事件 / 秘境 / 能量值 / 权限码 / REST 端点 / Web 管理页 / WebSocket 处理器；内置事件总线（10 种事件类型）；支持热重载与可视化插件生成器
- **适配器框架**：`AdapterManager` 统一管理外部系统适配器（Minecraft 服务端 / Minecraft 玩家代理 / QQ 官方 API 等）
- **扫描注册机制**：物品、游历事件、秘境、指令均通过 classpath 扫描自动注册，新增内容无需修改核心代码
